1. 문제와 과제

  • 목표: 실기 휴머노이드가 장면·물체와 상호작용(HSI)하면서 (1) 다양한 배치·목표로 일반화, (2) 사람 같은 동작, (3) 끊기지 않는 물체 인지를 함께 갖추기 (p.1).
  • 기존 방식의 문제: 처음부터 RL 은 보상·상태 전이 설계가 무겁고 동작이 부자연스러움, 동작 추종(tracking)은 참조에 묶여 새 배치로 일반화가 안 됨, 시뮬 HSI 연구는 완벽한 물체 관측을 가정 (p.1–2).
  • 과제 4 개 + 스타일 보행: Carry Box(걸어가기 → 들기 → 나르기 → 놓기, 4 단계), Sit Down, Lie Down, Stand Up, 공룡 걸음·하이니 보행 (p.5, 부록 A).
  • Carry Box 장면: 시뮬에서는 얇은 받침판 두 장이 시작·목표 높이의 상자를 받침. 에피소드 20 s (p.10; carrybox_config.py episode_length_s = 20).

4. 보상 · 종료 · 커리큘럼

전체 보상

  • 논문: r = wG·rG + wR·rR + wS·rS, wG = 0.7, wR = 0.7, wS = 0.3 (p.3, p.12 표 VIII). 스타일 rS = −log(1 − D) (식 4).

11. 우리에게 가져올 것

  1. 가져올 것 — 거리 게이트 + 한쪽 높이 보상 꼴: 상자 0.7 m 밖이면 집기 보상 0, 높이 항은 exp(−3·max(h* − hbox, 0)) 로 모자랄 때만 깎고 h* 를 넘으면 상수. 가중 비율도 참고(손 위치 0.7 : 상자 높이 2.0 — 들기가 손 맞추기보다 3 배 큼). 단 h* = 0.72 m 는 G1 키 기준 절대 높이라 그대로 쓰지 말고, K1 은 "시작 높이(0/0.1/0.2/0.3 m 받침) + Δh" 로 정한다.
  2. 가져오지 말 것 — 접촉 보상 없이 손 평균만 맞추기: PhysHSI 는 AMP 운반 동작이 두 손 클램프 모양을 강제해서 손 평균–상자 중심 항만으로 됐다. 우리는 상체에 스타일 사전이 없고 dev10 v2 에서 한 손 밀기 국소해를 이미 겪었다. 두 손 평균을 상자 중심에 두는 항은 손을 앞·뒷면에 대도 만족되므로, 손 목표를 상자 좌우 옆면 중심 두 점으로 바꾸고 min(왼 힘, 오른 힘) 접촉 항을 따로 둔다.
  3. 가져올 것 — 혼합 초기화와 그 절제 결과: 단순 RSI(5.70 %)가 RSI 없음(41.24 %)보다 나쁘고 혼합 RSI 가 79.34 % (p.6 표 II). 우리는 MoCap 이 없으니 "쪼그려 손이 옆면 근처에 있는 상태"를 teacher 자신의 롤아웃 스냅숏에서 뽑아 일부(예: 20–50 %)만 그 상태에서 시작하고, 나머지는 서 있는 기본 자세 + 완전 무작위 상자 배치(높이 0–0.3 m, 앞 0.04–0.30 m, 옆 ±0.15 m, yaw ±40°)로 둔다. 스냅숏 장면 그대로만 쓰면 과적합한다는 것이 이 표의 교훈.
  4. 가져올 것 — 단계적 엄격화: 1 단계는 느슨한 종료(상자 넘어짐 종료 끔)·약한 스타일, 2 단계에서 종료 켜고 가중을 올려 이어학습. 우리 대응: 처음엔 행동 변화율·자세 벌점을 작게 두고 집기가 생긴 뒤 키운다. 단, 이어학습 때 critic 입력이 바뀌면 critic 을 무작위로 새로 만들면 첫 갱신에 actor 가 망가지니 넓힌 입력만 0 으로 늘려 이어 붙인다.
  5. 가져올 것 — 환경 안에서 행동을 자르지 않음: PhysHSI 는 clip ±100(사실상 없음) + action rate −0.03 + L2C2(정책 0.111, 가치 0.011)로 매끄러움을 만든다. dev10 v2 의 "환경 안 자르기 → std 발산"과 "켜짐/꺼짐 포화"에 대한 대안으로, 상위 출력은 자르지 말고 범위 밖 L2 벌점 + L2C2 식 관측 보간 평활 손실을 시험해 볼 만하다.
  6. 가져올 것 — 시야 기반 가림을 teacher 단계에서 미리: 상자가 카메라 FOV 밖(수평 85–90°, 수직 55–60° 무작위, 거리 2.5 m)이면 상자 관측을 가리는 방식은 성공률 손실이 작았다(85.90 → 79.34 %). 우리 D436 student 도 잡은 뒤 상자가 너무 가깝거나 시야를 벗어나므로, teacher actor 에 "보이는가" 기준의 가림이나 잡음(위치 ±0.05 m, 회전 ±5°)을 넣어 student 가 흉내 낼 수 있는 teacher 로 만든다. 접촉력·질량은 critic 전용으로.
  7. 참고 값 — DR: payload [−2, 5] kg, 몸통 외란 ±50 N(8 스텝마다), 행동 지연 0–20 ms, Kp·Kd 0.9–1.1, 관측 잡음(각속도 0.3, 관절 속도 2.0). dev12 가 이미 손 하중 0–5 kg 으로 학습됐으므로 상위 학습에서는 상자 0.5–2 kg 에 상자 마찰(0.5–1.2)·반발(0–0.2)을 실제로 켜서 쓴다(PhysHSI 공개 코드는 꺼져 있었다).
  8. 가져오지 말 것 — 29 관절 직접 출력 + 전신 AMP: 우리는 하위를 고정하고 상체 11 + 골반 명령을 내는 구조라 이 논문의 행동 공간은 맞지 않는다. 다리 AMP 는 dev12 에 이미 있고, 상체 AMP 를 붙이려면 K1 상체 집기 참조 클립이 필요하다.
  9. 가져오지 말 것 — 인지 파이프라인: LiDAR 수동 지정 + AprilTag 는 실험실 장치. 우리는 깊이 student 로 간다. 다만 "멀면 거친 안내, 가까우면 정밀"이라는 나눔은 나중의 접근 단계에 참고.
  10. 기대치 조정: 같은 고무 손 G1 도 실기 바닥 상자 2/3, 4.5 kg 0/3, 넓은 상자는 도달 한계로 실패했다. 우리 상자(폭 40.5 cm, 0.5–2 kg)는 PhysHSI 학습 범위(폭 ≤ 0.39 m) 위쪽 끝이고 K1 팔은 G1 보다 짧으니, 바닥 상자 도달은 보상보다 골반 높이·pitch 범위와 상자 앞 거리 분포로 풀어야 한다(우리 dev10 v2 결론과 같은 방향).
  11. 평가 방식: 시드 5 × 1000 에피소드를 평균 ± 표준편차로 보고하면서도 표마다 값이 달랐다. 우리는 고정 평가셋·체크포인트 이웃 비교로 같은 숫자를 다시 낼 수 있게 한다.
