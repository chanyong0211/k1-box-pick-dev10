로컬 PDF arXiv 2412.09149 프로젝트 페이지 유사도 3 코드 없음
teacher 보상에 "teacher 와 (대리) student 의 행동 분포 KL" 벌점을 넣고, PPO 손실에도 같은 KL 의 기울기를 더하며, 세 망(teacher·student·대리 student)이 행동 디코더 하나를 공유하게 해 teacher 가 student 가 볼 수 있는 행동을 고르게 만든다. 팔이 카메라를 가리는 Franka 서랍 열기 student 성공률 DAgger 0.34 → 0.88, 쿼드로터 장애물 회피 0.08 → 0.46. 실기 실험 없음.

1. 문제와 과제

  • 특권 모방 학습의 함정: teacher 는 student 가 흉내 낼 수 있는지 모른 채 학습되어, student 관측으로는 추론할 수 없는 목표 행동을 준다 (p.2).
  • 이론 근거: 보상이 |r| ≤ rmax 일 때 J(πT) − J(πS) ≤ 2√2 rmax √ε / (1 − γ)², 여기서 Es∼dπT[DKL(πT(·|s), πS(·|s))] ≤ ε (식 1–2, p.3). 격차의 상한은 teacher 상태 분포에서의 행동 차이로 정해진다.
  • 관점 전환: 보통은 student 를 고쳐 이 KL 을 줄이지만, 여기서는 teacher 를 고쳐 과제 보상과 student 정렬을 함께 최적화한다 (p.3).

목표 함수 (식 3–5, p.3):

J̃(π_T) = E_{s∼d_πT, a∼π_T}[ r(s, a) − D_KL(π_T(·|s), π_S(·|s)) ]
        ∝ E_{τ∼p_θ}[ R(τ) − D_θ(τ) ],  D_θ(τ) = Σ_t γ^t D_KL(π_T(·|s_t), π_S(·|s_t))

기울기 (식 6–8, p.4):

∇_θ J̃ = ∫ ∇_θ p_θ(τ) (R(τ) − D_θ(τ)) dτ   ← 정책 기울기: KL 이 보상 벌점으로 들어감
       − ∫ p_θ(τ) ∇_θ D_θ(τ) dτ             ← KL 기울기: teacher 가중치를 student 쪽으로 직접 당김
  • 첫 항: 정렬이 나쁜 상태를 피하도록 탐색과 경로를 바꾼다.
  • 둘째 항: teacher 상태에서 teacher 행동 분포를 student 에 맞추는 직접 지도.

critic 을 빼고 망 셋 + 공유 디코더 하나 (p.4).

③ 정렬 (그림 1d)

그림 1 (p.1), 4.2 절 (p.5–6), 알고리즘 1 (p.15). 점선 = 그 단계에서 갱신하지 않는 것.

  • 정렬 단계는 기울기를 student 쪽(FS)에만 흘린다. 양쪽으로 흘리면 상수 출력으로 무너지기 때문 (p.6).
  • teacher 는 정렬 단계에서 변하지 않고, 정책 갱신 단계에서만 바뀐다 (p.6).
  • 대리 student 덕분에 student 관측(영상)은 일부 env·일부 스텝에서만 렌더링하면 된다 (p.4, p.5).
  • 공유 디코더 이유: teacher 가 많은 상호작용으로 배운 고수준 특징 상관을 student 도 쓰고, 정렬 데이터가 적어도 디코더는 넓은 teacher 상태에서 학습돼 더 강건 (p.4–5).

짝 L1 정렬FS 를 FT 특징과 디코더 활성에, F̂S 를 FS 특징에기울기는 받는 쪽에만

KL 을 풀어 쓰면 (식 9–10, p.5)

D_KL = ½ [ log(|Σ_S| / |Σ_T|) − d + Tr(Σ_S⁻¹ Σ_T) + (μ_T − μ_S)ᵀ Σ_S⁻¹ (μ_T − μ_S) ]
Σ_T = Σ_S (공유 디코더의 상태 무관 σ)  →  D_KL = ½ [ const + (μ_T − μ_S)ᵀ Σ_T⁻¹ (μ_T − μ_S) ]
  • teacher 가 확신(σ 작음)하는데 student 와 어긋나면 손실이 커진다.
  • 저자 설명: 그 결과 기울기가 공분산을 키워 탐색이 늘고, student 가 배울 수 있는 행동을 찾을 확률이 오른다 (p.5). 즉 이 항은 σ 를 키우는 방향으로도 작용한다.

7. 결과

색 미로 (그림 2, p.6, p.8)

  • 정렬 없는 teacher: 용암 사이 지름길(미로 안). BC·DAgger·정렬 없는 student 는 용암과 길을 구분 못 해 실패.
  • 정렬 있는 teacher: 미로를 돌아가는 바깥 경로(테두리 3 칸). student 가 모든 시험(5 학습 × 15 평가 env)에서 목표 도달.
  • 돌아가는 경로는 보상이 희소한데도 찾아냈다 → 벌점이 필요한 탐색을 막지 않았다.

  • 본문과 표가 다르다: 본문은 "최대 0.77 vs DAgger 0.47, BC 0.27", "정렬이 17 % 향상"이라 쓰지만 표 3 은 0.88 / 0.34 / 0.16, 0.61 → 0.88 (+0.27). 이 페이지는 표를 따른다.

10. 한계

  • 실기 검증 없음, 과제가 작다(표 미로, 기둥 4 개, 서랍 하나). 다리 로봇·접촉 많은 조작은 없음.
  • 망이 작고 비순환(MLP 3 층, 동결 DINOv2). 이력·기억이 필요한 student 에서 대리 student 가 잘 흉내 내는지는 시험 안 됨.
  • teacher 를 student 와 함께 처음부터 학습해야 한다. 이미 학습된 teacher 를 재사용할 수 없고, student 구조를 바꾸면 teacher 도 다시.
  • KL 기울기가 σ 를 키운다(p.5). σ 가 커지면 벌점 자체도 줄어 teacher 가 "자신 없음"으로 벌점을 피할 여지가 있다(식 10 에서 추론).
  • 본문과 표 3 의 숫자가 다르고(0.77/0.47/0.27 vs 0.88/0.34/0.16), 비교 방법 이름이 본문 DHBC·표 DWBC 로 엇갈린다. 쿼드로터 보상 식의 부호가 불분명하고 관측 차원 표기가 깨져 있다(p.14).
  • 쿼드로터의 λ, 행동 정의, Franka 종료 조건 등 재현 값이 빠져 있다.
  • teacher 가 student 를 위해 덜 최적인 경로를 택한다(미로). 과제에 따라 teacher 성능 손해가 있을 수 있다.

11. 우리에게 가져올 것

  1. 먼저 비대칭의 정체를 잰다: v2 격차 21 %p(90 → 69, Isaac)가 "student 가 못 보는 정보" 때문인지 확인. 후보는 손–상자 접촉, 상자 질량, 그리고 숙이며 두 팔을 상자 옆으로 넣을 때 상자 모서리가 26×64 crop 밖으로 나가거나 팔에 가리는 것. 서랍 과제(팔이 손잡이를 가림)와 같은 꼴이다. Isaac 에서 "상자 픽셀이 crop 안에 남은 비율"을 단계별로 기록하는 진단부터(추론).
  2. 싼 순서로: ① 접촉·질량을 critic 전용으로(DextrAH-G) → ② 그래도 격차가 크면 SITT 의 공유 디코더 + 특징 L1 정렬(teacher 보상 불변, 서랍 0.34 → 0.61) → ③ 마지막으로 KL 두 항(0.61 → 0.88).
  3. KL 벌점 크기: λ1 은 0.025–0.1 에서 모두 0.77 이상, 0.025 가 최고(0.95)였다. 다만 보상 단위가 달라 숫자를 그대로 옮기지 말고, 스텝당 과제 보상 대비 KL 벌점 비율을 로그로 보며 작게 시작한다(추론). 손실 쪽 KL 기울기 λ2 출발점 0.01(서랍)·0.001(미로).
  4. 대리 student 는 필요할 때만: 대리 망은 영상 렌더가 비쌀 때(4,096 중 128 env 만 렌더) 쓰는 장치다. 우리 깊이가 레이캐스트로 모든 env 에서 싸게 나온다면 진짜 student 행동으로 KL 을 계산하는 쪽이 단순하고 정확하다(추론).
  5. σ 를 공유하고 상한을 둔다: SITT 의 KL 은 ΣT = ΣS 일 때 σ−2 가중 평균 차가 된다. 우리 rsl_rl teacher 는 환경 안 자르기로 std 가 발산한 이력이 있으므로, KL 항을 넣기 전에 std 상한을 먼저 건다.
  6. "지각 의식" 지표를 평가셋에 추가: 쿼드로터의 속도–시선 각·시야 안 장애물 수처럼, 우리도 접촉 직전 0.5 s 동안 상자 가시 비율, 상자 중심의 crop 안 위치를 teacher·student 둘 다 측정해 체크포인트 비교 지표로 쓴다(추론).

가져오지 말 것

  • teacher·student 동시 학습을 첫 단계로: teacher 를 다시 처음부터, 그것도 student 구조에 묶어 학습해야 한다. 구조가 아직 바뀌는 단계에서는 비용이 크다. 위 ①이 효과를 보면 필요 없을 수 있다.
  • 동결 DINOv2 RGB student: 우리는 깊이 26×64 × 6 프레임. 영상 인코더 선택은 이 논문 결과와 무관.
  • λ 숫자 그대로(미로 1.9, 서랍 0.05): 보상 크기·행동 차원(우리 17)이 다르다.
  • Isaac → MuJoCo 격차(69 → 50 %) 해결책으로 기대하기: SITT 는 정보 비대칭(같은 시뮬 안 teacher–student 차이)만 다룬다. 시뮬 간 물리 차이는 별도 문제.
  • 본문 수치(0.77, 0.47, 0.27, 17 %): 표와 어긋난다. 인용은 표 3 값으로.
