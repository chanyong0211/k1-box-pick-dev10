1. 문제와 과제

  • 문제: ASE·CALM 같은 잠재 기술 공간은 작은 전문 데이터(걷기·검술)에서만 잘 되고, AMASS 처럼 크고 정리 안 된 데이터로 넓히면 덮는 범위가 무너진다. 반대로 "운동학 동작을 추적기에 넣기"는 RL 탐색 공간으로 고차원·물리 제약 없음이라 나쁘다(p.1–2).
  • 아이디어: (1) 모든 AMASS 동작을 따라 하는 추적기를 RL 로 먼저 만들고, (2) 그 기술을 변분 정보 병목(VAE 꼴)으로 증류하되, (3) 고유감각에 조건 붙은 학습 prior 를 함께 배워, prior 에서 뽑기만 해도 사람다운 동작이 나오게 한다(p.2).

무작위화 · 규모

  • 도메인 무작위화·관측 잡음·지연: 논문에 없음. 체형은 SMPL 평균 체형 고정(p.4).

6. teacher → student / 증류

이 논문의 핵심 기여가 증류다. 교사 PHC+ 와 학생 PULSE 는 같은 관측·같은 행동 공간을 쓰고, 차이는 학생 쪽 정보 병목(32 차원 VAE)뿐이다(p.16 §C.1).

항목내용
자료 수집학생 πPULSE 가 모방 과제를 직접 굴려 상태를 모으고, 그 상태에 교사가 행동 aPHC+ 를 붙인다(DAgger 와 같은 방식, p.3·p.5). 코드: only_kin_loss 일 때 학생은 평균 행동으로 굴림
손실순수 지도학습(행동 회귀 + Lregu + KL). RL 손실 없음
표본 추출학습 때는 z ∼ N(μe, σe) 재매개화, 평가 때는 μe
진행형 학습교사와 같은 어려운 사례 채굴(Q̂hard)로 드문 동작 비중을 맞춤
정보 손실병목 없이 증류하면 100 %, 병목을 두면 훈련 99.8 %·시험 97.1 %(표 1). VAE 재구성 오차와 같은 성격

RL 과 섞으면 나빠진다

  • 디코더를 가우시안으로 보고 RL 로 함께 학습(kickstarting 식)하면 "잠재 표본 + RL 탐색 표본"이 겹쳐 불안정하다(p.5).
  • 표 3: RL 을 섞은 R4 는 VR 추적 시험 성공 71.0 %, 순수 지도 R6 는 93.4 %.
  • 표 6: 증류 없이 RL 만으로 PULSE 를 1010 샘플 넘게 학습하면 훈련 72.0 %·시험 32.6 %(증류 99.8 %·97.1 %).
  • 주의: 이 결과는 "학생도 같은 특권 관측을 받는 VAE 병목" 조건이다. 학생이 교사보다 정보를 덜 받는 우리 경우(깊이 student)와 같은 조건은 아니다.

  • 생성 과제(그림 4): 네 과제 모두 PULSE 가 최고 return, 처음부터 학습이 가장 가깝지만 비자연스러운 동작. CALM 은 스타일 보상을 빼고 학습해 탐색이 막혔다(p.8). 그림을 눈으로 읽으면 Reach 에서 PULSE 약 0.8, ASE 약 0.65.

11. 우리에게 가져올 것

  1. 상위 행동 = "명목 + 잔차" — PULSE 의 가장 큰 효과(표 3: prior 잔차 없으면 93.4 % → 18.1 %). 우리에겐 학습 prior 가 없으므로 명목을 손으로 정한다: 단계(접근·숙임/쪼그림·조이기·들기·버티기)별 명목 골반 높이·pitch 와 상체 11 명목 자세(손바닥이 상자 옆면을 향하는 자세). 상위 정책은 그 위 잔차만 내고, 출력층을 0 근처로 초기화해 첫 탐색이 명목 동작 주변에서 시작하게 한다.
  2. 잔차 크기는 작게, 탐색 분산은 고정 — PULSE 는 prior σ 가 너무 작아 고정 분산(논문 0.22, 코드 σ 0.37)을 썼다. 우리: 잔차를 [−1, 1] 정규화 단위로 두고 관절별 최대 잔차(예: 팔 ±0.3 rad, 골반 높이 ±0.1 m — 시작값, 추론)로 사상, σ 는 고정 또는 상한. v2 의 σ 폭주(환경 안 자르기 + 학습 σ)를 피한다.
  3. 출력 시간 평활 벌점 — Lregu(연속 잠재 차 벌점)가 탐색에 유리했다(36.9 → 45.6 %, 60.8 → 93.4 %). 우리 대응은 상위 출력 변화율 벌점(‖at − at−1‖²). dev12 는 상체 목표의 저역 통과값과 변화율을 관측하므로, 변화율을 dev12 학습 분포 안에 두는 효과도 있다. 켜짐/꺼짐 포화 완화에도 직접 작용.
  4. 어려운 사례 채굴 — PHC+·PULSE 모두 실패한 시퀀스를 모아 집중 학습해 98.9 → 100 % 를 만들었다(표 5: 진행형 92.0 → 98.5 %). 우리: 상자 조건(받침대 0/0.1/0.2/0.3 m, 앞 0.04–0.30 m, 옆 ±0.15 m, yaw ±40°, 0.5–2 kg)을 칸으로 나눠 칸별 성공률을 기록하고 실패 칸을 더 자주 뽑는다. 바닥 상자 도달 한계·한 손 밀기 국소 최적이 특정 칸에 몰리는지도 이 표로 보인다.
  5. 증류는 "학생이 굴리고 교사가 라벨"부터 — PULSE 는 순수 DAgger 식 지도학습이 RL 혼합보다 좋았다(93.4 % 대 71.0 %). 우리 student 도 먼저 순수 DAgger 로 돌리고, 격차가 남으면 RL 미세조정을 작은 비중으로 따로 붙인다. 단, PULSE 는 학생도 같은 특권 관측을 받았다. 우리 student 격차의 원인(접촉 정보)은 이 논문이 다루지 않는다.
  6. 상위 주기는 너무 낮추지 말 것 — 같은 저자 실험에서 ASE 잠재를 30 Hz 로 쓰면 6 Hz 보다 추적이 낫고 가속 오차가 6 배 작았다(19.5 대 117.7). 정밀 접촉(조이기·들기) 단계는 dev12 50 Hz 에 가까운 주기로 팔 잔차를 내고, 평활은 변화율 벌점으로 잡는 편이 맞아 보인다(추론).
  7. 에너지 벌점으로 떨림 억제 — PHC+ 는 −0.0005 Σ|τω|² 로 고주파 떨림을 막았다. 상위 학습 때 팔 관절에 같은 꼴을 작은 계수로 넣을 수 있다.
  8. 가져오지 말 것 ①: VAE 잠재 저수준 — 대규모 동작 데이터 + 1010 샘플 교사가 필요하고, 잠재는 해석이 안 돼 dev12 의 골반 명령 인터페이스를 버려야 한다. 코드상 잠재 크기 제한도 없다.
  9. 가져오지 말 것 ②: "같은 관측"을 전제한 증류 결론 — 깊이 student 는 교사보다 정보가 적어, PULSE 의 "RL 섞으면 나쁨"을 그대로 일반화하면 안 된다. 수치·아이디어만 참고(LICENSE 없음, 코드 복사 금지).
