What Matters In On-Policy Reinforcement Learning? A Large-Scale Empirical Study

Marcin Andrychowicz, Anton Raichuk, Piotr Stańczyk, Manu Orsini, Sertan Girgin, Raphael Marinier, Léonard Hussenot, Matthieu Geist, Olivier Pietquin, Marcin Michalski, Sylvain Gelly, Olivier Bachem · Google Research, Brain Team · ICLR 2021 (로컬 PDF 는 arXiv v1 2020-06, 48쪽 — 학회판과 그림 번호가 다를 수 있음) · 로봇 없음: Gym Hopper·Walker2d·HalfCheetah·Ant·Humanoid -v1 · MuJoCo 2.0

로컬 PDF arXiv 2006.05990 유사도 4 라이선스 –
PPO 기반 통합 구현에서 68개 선택(C1–C68)을 주제별로 무작위로 바꿔 25만 개 넘는 에이전트를 학습. 가장 크게 작동한 것은 초기 행동 분포(평균 0·작은 std: 정책 마지막 층 100배 축소만으로 Humanoid +66 %, 초기 std 0.5 가 5개 중 4개 환경에서 최고)와 관측 정규화(Humanoid 약 2,720 vs 470). clip 대신 tanh 는 "약간" 나음, 엔트로피·KL 규제는 HalfCheetah 외엔 무효 (p.4–8).

1. 문제와 과제

질문: 논문에 잘 안 적히는 구현 선택(초기화, 정규화, 손실 세부 등)이 성능을 얼마나 좌우하나? 결론을 실무 권고로 정리 (p.1–2).

실험 설계 (p.2–3)

  • 통합 에이전트: OpenAI baselines PPO 와 같은 선택으로 PPO 논문 성능 재현을 확인한 뒤, 구현 결정마다 선택지 번호(C1–C68)를 붙임.
  • 선택을 8개 주제 묶음으로 나누고, 묶음 안 선택만 균등 무작위, 나머지는 기본 설정(표 2). Adam lr(C24)은 상호작용이 의심돼 모든 묶음에 포함.
  • 설정마다 3 시드. 10만 스텝마다 확률적 정책으로 100 에피소드 평가 → 평균(곡선 아래 면적 비례) → 3 시드 중앙값이 설정 점수.
  • 분석 둘: ① 선택값별 조건부 95번째 백분위(+ 이항 신뢰구간) — "나머지를 랜덤 서치 약 20개 설정으로 맞췄을 때 기대 성능" ② 상위 5 % 설정 안 선택값 분포 — 균등 표본이므로 과다 대표면 중요.

2. 시스템 구조

행동 분포 매개화 (부록 B.8): π = Tu( N( xμ, Tρ(xρ + cρ) + ερ ) ), cρ = Tρ−1(iρ − ερ) — 초기 std 가 정확히 iρ 가 되게 하는 오프셋.

관측 → 평균·표준편차 정규화 (C64), ±omax 자르기 (C65)→ 정책 MLP (분리 C47, 폭·깊이 C49·C52, 활성 C55, 초기화 C56)→ 평균 xμ (마지막 층 가중치 × C57)

표준편차 경로

xρ: 전역 매개 또는 망 출력 (C59)→ + cρ (초기 std C61)→ Tρ: exp 또는 softplus (C60) + ερ (C62)→ 가우시안 표본 x→ Tu: clip 또는 tanh (C63)→ 환경 행동 [−1, 1]
  • tanh 의 밀도: u = tanh(x) 면 log pu(u) = log pθ(x) − log tanh′(x). 이 항은 정책 손실(∇θlog p 만 씀)과 KL(같은 표본의 log 차)에서 상쇄되고, 엔트로피에서만 남는다: H = E[−log pθ(x) + log tanh′(x)]. 이 항이 극단 행동을 벌해 tanh 포화와 기울기 소실을 막고 엔트로피 상한을 준다 (B.8).
  • exp 안전장치: 지수를 [−15, 15] 로 자르고 기울기는 1 로 통과시킴. 그냥 exp 는 일부 실행에서 NaN (각주 10, 25).
  • PPO 손실: 비율 하한을 1 − ε 대신 1/(1 + ε) 로 (대칭) (각주 19).
  • 데이터 루프 (B.1): env C1 개를 동기로 돌려 C2 개 전이 수집(env 당 C2/C1 스텝 조각) → C3 epoch × 크기 C4 미니배치. 미니배치 방식 C5 4종: 조각 고정 / 조각 섞기 / 전이 섞기(PPO2 원본, 이점은 반복 시작에 한 번) / 전이 섞기 + epoch 마다 이점 재계산(이 논문 제안).

11. 우리에게 가져올 것

  1. 정책 마지막 층 × 0.01, 편향 0: 초기 평균 행동이 관측과 무관하게 0 근처. 우리 행동을 "명목 자세 / 현재 명령 대비 델타"로 정의하면 초기 정책 = "명목 유지"가 되어 v2 의 켜짐/꺼짐 포화 출발을 피한다. 우리 rsl_rl 버전의 actor 초기화에 이런 축소가 있는지 먼저 확인하고, 없으면 actor 생성 직후 마지막 Linear 가중치에만 0.01 을 곱한다.
  2. 초기 std 0.5 유지 (9월 판 k1_boxlift teacher 도 0.5). 단 이것은 행동이 [−1, 1] 로 정규화됐을 때의 값이다 — 17차원 각각을 "dev12 가 실제로 도달하는 범위"로 [−1, 1] 에 맞춘 뒤 0.5 를 쓴다. 델타 행동을 누적하면 무작위 탐색이 걸음마다 쌓이므로 누적 배율을 작게 잡거나 초기 std 를 더 낮춰 A/B (추론).
  3. tanh 스쿼시 + 엔트로피 0(또는 log-det 포함): 논문에서 clip 은 엔트로피 규제 없이 썼고 문제없었다(약간 나쁠 뿐). 우리 v2 의 std 발산은 "환경 안 자르기 + 엔트로피 보너스 0.005" 조합으로 보인다 — 잘린 영역에선 반환이 σ 에 둔감해 엔트로피 기울기만 σ 를 키운다(추론). 처방: ① 엔트로피 보너스를 0 또는 매우 작게(논문: 초기화가 탐색을 보장) ② tanh 를 쓰면 엔트로피에 −log tanh′(x) 항이 들어가 극단 행동을 벌하고 엔트로피가 유계 ③ PPO 비율은 저장한 tanh 이전 표본 x 의 가우시안 log-prob 만으로 계산(log-det 상쇄) — atanh(±1) 역산을 피한다.
  4. 관측 정규화 켜기: 9월 역할 분리 판 teacher(k1_boxlift)는 actor·critic 관측 정규화가 꺼져 있었다 (rsl_rl_cfg.py actor_obs_normalization=False). 논문에서 Humanoid 는 정규화 없이 약 1/6. 손으로 스케일을 맞췄더라도 empirical normalization 을 켠 A/B 를 첫 실험에 넣는다. student 쪽도 같은 확인. (v2 sonic_pick 의 TRL PPO 설정은 이 항목을 따로 확인하지 않았다.)
  5. 가치 쪽: PPO 식 가치 자르기 끄기 A/B (논문: 문턱과 무관하게 손해, dev12 설정은 use_clipped_value_loss: True — dev12 cfg.py), 가치 정규화는 우리 rsl_rl 에 있으면 A/B (Walker2d 처럼 손해 날 수도 있음), 가치망은 넓게·분리.
  6. GAE λ 0.9 · γ 확인: 우리 기본 λ 0.95 → 0.9 는 낮은 우선순위 A/B. γ 는 상위 제어 주기에서 유효 지평 1/(1−γ) 스텝이 박스 과제 길이(접근 → 쪼그림 → 조이기 → 들기)를 덮는지 계산해 고른다.
  7. epoch 마다 이점 재계산: 전이 섞기 미니배치에서 소폭 이득. 비용이 작으면 넣을 수 있으나 우선순위 낮음.

가져오지 말 것 / 주의

  • "clip 도 괜찮다"를 우리 문제에 그대로 적용하지 말 것: 엔트로피 보너스 0, 1–2M 스텝 조건의 결과다. 우리는 v2 에서 실제로 std 가 발산했다.
  • tanh 활성 권고: 얕은 64 폭 망 결과. 우리 ELU [512, 256, 128] 를 바꿀 근거는 약하다(Humanoid tanh 2,770 vs ELU 2,350 정도의 차).
  • env 수·배치 결론: 256 env 이하 범위의 표본 효율 결과. 수천 env GPU 학습의 벽시계 최적과는 다르다.
  • 모든 수치는 막대그래프 근사값이므로 정확한 비율 비교에 쓰지 말 것 — 본문 수치(+66 %, +30 %, +15 %)만 인용.
