1. 문제와 과제

  • 문제: 물리 캐릭터 제어는 과제마다 처음부터 학습한다. 걷기·균형 같은 공통 기술을 매번 다시 배우고, 보상만으로는 자연스러운 동작이 안 나온다(p.1–2).
  • 아이디어: 분할·주석 없는 대규모 동작 데이터로 "잠재 z → 기술" 저수준 정책을 한 번 사전학습하고, 새 과제는 z 를 고르는 상위 정책만 학습한다(p.3–4, 그림 2).
  • 사전학습 목표(식 2): 정책의 상태 전이 분포와 데이터 분포의 Jensen–Shannon 발산을 줄이고(모방), 기술 z 와 전이 (s, s′) 의 상호정보 I(s, s′; z) 를 키운다(기술 발견, 계수 β).

규모 · 무작위화

  • 4,096 env, V100 1 대, 시뮬 120 Hz(p.10 §10.1). 코드: 물리 하위 스텝 2, controlFrequencyInv 2.

  • 탐색 보조(코드만): enable_eps_greedy — env 별로 확률 1 − exp(10(i/(N−1) − 1)) 만큼만 확률 행동을 쓰고 나머지는 평균 행동. 판별기가 "잡음 떨림"만 보고 가짜를 가려내지 않게 하려는 것(amp_agent.py 주석). 행위자 손실은 확률 행동 표본에만 건다.

10. 한계

  • GAN 계열이라 모드 붕괴가 남는다. 기술 발견 목표로 줄였어도 데이터의 다양성을 다 담지 못한다(p.14 §11).
  • 표본이 매우 많이 든다(100 억, 10 일).
  • 저수준이 가끔 떨림·급격한 움찔·과한 회복 동작을 낸다(p.14).
  • 하위 과제가 단순하다(도달·이동·타격). 손 접촉·물체 잡기·하중 운반은 없다.
  • 정밀도 한계: Reach 평균 오차 8.8 cm. 잠재만으로는 손끝을 cm 단위로 맞추기 어렵다.
  • 처음부터 학습한 정책보다 return 이 낮은 과제가 많다(자연스러움과 맞바꿈).
  • 실기·무작위화·지연이 전혀 없다.

11. 우리에게 가져올 것

  1. 환경 안 자르기 대신 "평균 경계 + 고정(또는 상한) σ" — v2 의 σ 폭주(잘린 행동에 벌점 없음)와 직접 맞닿는다. ASE 코드는 상위 평균에 tanh, σ = e−2.3 ≈ 0.10 고정(learn_sigma: False), 저수준에는 |μ| > 1 초과분 제곱 벌점 계수 10 을 둔다. 우리 상위 출력(골반 명령 + 상체 11)을 [−1, 1] 정규화 단위로 정의하고, μ 에 tanh 또는 경계 벌점, σ 는 0.1 근처 고정이나 log σ 상한으로 시작한다. ASE 저수준도 환경 래퍼에서 행동을 ±1 로 자르지만, σ 가 고정이고 평균이 경계 벌점에 묶여 있어 σ 가 커질 길이 없다. 환경에서 자르더라도 잘린 양 벌점을 함께 둔다.
  2. 상위 행동 공간을 "하위가 실제로 따라가는 범위"로 만든다 — ASE 는 잠재를 구면으로 묶어 상위가 분포 밖 명령을 못 내게 했다(p.5–6). 우리 대응: 상위 출력을 dev12 학습 범위(높이 서기 0.335–0.77 m · 걷기 0.42–0.77 m, pitch ±45°·roll ±10° 는 서 있을 때만, vx ±0.8 · vy ±0.4 · ωz ±1.0)로 사상하고, 상태에 따라(걷는 중이면 높이 하한 0.42 m, roll 0) 범위를 바꾼다. v2 의 "추종기가 못 따라가는 허리 출력" 재발 방지.
  3. 상위 주기를 낮추고 보상을 하위 스텝 평균으로 — ASE: 하위 30 Hz 위 상위 6 Hz(5 스텝 유지), 보상은 5 스텝 평균, 종료는 OR. 우리: dev12 50 Hz 위에 골반 명령 10 Hz(5 스텝 유지)부터 시험. 명령 전환이 줄어 v2 의 켜짐/꺼짐 포화·떨림이 줄 것으로 본다(추론). 단, dev12 가 관측하는 상체 목표 변화율이 학습 분포 밖으로 튀지 않는지 계단 입력에서 확인.
  4. "분포 안" 스타일 보상 0.1 — ASE 는 고정 판별기 −log(1 − D) 를 0.1(코드상 ×2) 가중으로 더해 떨림을 줄였다. dev12 는 다리 전용 AMP 판별기를 이미 가지므로, 이를 고정해 상위 보상에 0.1 로 넣는 변형이 가능하다. 단, dev12 AMP 데이터에 깊은 쪼그림·숙임이 없으면 박스 집기 자세 자체를 벌주므로, 쪼그림 0.335 m·pitch 45° 상태에서 판별기 점수를 먼저 보고 넣을지 정한다.
  5. 하위의 "응답성" 조건 확인 — ASE 는 잠재를 1–150 스텝마다 바꿔 학습해 중간 전환에 반응하게 했다(§6.4). dev12 의 명령 재표본 간격이 상위가 바꿀 속도보다 훨씬 길면 상위의 빠른 명령 변화가 하위 학습 밖이다. dev12 명령 재표본 간격을 상위 주기와 맞춰 본다.
  6. 평가는 여러 시드 × 많은 에피소드 평균 ± 표준편차 — ASE 표 1 은 저수준 3 개 × 4,096 에피소드다. v2 의 "체크포인트마다 성공률이 오르내림"은 고정 시드 평가 세트(예: 4,096 에피소드)로 체크포인트를 고르고 표준편차와 함께 기록해 우연과 구분한다.
  7. 가져오지 말 것 ①: 잠재 기술 저수준 자체 — 100 억 샘플·10 일·동작 데이터가 들고, 출력이 해석 불가한 64 차원이라 dev12 의 명시 골반 명령 인터페이스를 버려야 한다. 팔은 우리 쪽에서 외부 PD 로 직접 주므로 잠재로 감쌀 이유도 없다.
  8. 가져오지 말 것 ②: 잠재만으로 정밀 접촉 — Reach 평균 오차 8.8 cm 는 37 cm 상자를 두 손바닥으로 옆면에서 조이기에 너무 크다. 팔 관절 채널(명목 자세 + 잔차)은 남겨야 한다.
  9. 가져오지 말 것 ③: 캐릭터 설정값 — PD 강성 100–1000, 무작위화 0, 지연 0, 넘어짐 회복 사전학습(10 % 넘어진 자세 시작)은 K1 실기·고정 dev12 하체와 맞지 않는다. eps-greedy 결정 행동 혼합도 판별기를 학습할 때만 의미가 있다.
