Xie 상자 계층 제어: A* 계획 → 확산 모델 동작 생성 → RL 추종으로 상자 집기·나르기·내려놓기

Hierarchical Planning and Control for Box Loco-Manipulation

Zhaoming Xie, Jonathan Tseng, Sebastian Starke, Michiel van de Panne, C. Karen Liu · Stanford, Meta, UBC · Proc. ACM CGIT 6(2), Article 1, 2023 · 물리 시뮬 가상 캐릭터 (59 자유도, 로봇 아님) · RaiSim

로컬 PDF arXiv 2306.09532 유사도 3 논문만 (코드 링크 없음)
A* 경로 → 확산 모델이 걷기 전신 궤적 생성 → RL 정책이 물리 시뮬에서 추종. 집기·내려놓기는 "웅크렸다 일어서기" 참조 클립 하나에 상자 손 위치·직립·높이 보상을 더한 RL 정책 하나로 처리. 학습 받침 높이 0.3–0.7 m · 1 kg 에서 받침 0.05–1.00 m, 8 kg 까지 일반화 (상자 1 개, 3 회 이상 연속 성공 기준).

요약: 로봇이 아니라 캐릭터이고 상위가 RL 이 아니지만, "명목 웅크림-일어섬 궤적 하나 + RL 보정"으로 높이 범위를 넓게 덮은 것과 두 손 옆면 보상·상자 높이 일정 보상의 구체 식이 우리 집기 단계에 바로 대응한다.

1. 문제와 과제

  • 어수선한 3D 장면에서 상자를 집고, 들고 걷고, 내려놓아 원하는 배치로 옮기는 물리 시뮬 캐릭터 (p.1, p.4).
  • 기본 동작 4 개: 걷기(빈손), 걷기-나르기, 집기, 내려놓기. 기본 동작 그래프로 실행 순서를 정함 (그림 2, p.4).
  • 입력: 3D 장면 + 기본 동작 순서(사용자 지정). 출력: 애니메이션 (그림 2).
  • 상자 무게·크기·모양, 놓는 높이가 바뀌어도 되게, 여러 상자 쌓아 나르기도 (p.1–2).
  • 성공률 지표는 없고, 일반화는 "한 변수만 바꿔 집기·내려놓기를 3 회 이상 해내는 극값"으로 보고 (표 1).

2. 시스템 구조

이동 기본 동작 (걷기, 걷기-나르기)

3D 장면 + 기본 동작 순서→ kinodynamic A* + 3차 스플라인 평활→ 경유점 (루트 위치·방향)→ 확산 모델 (트랜스포머 인코더 + FiLM, 별도 학습)→ 전신 운동학 참조 궤적→ RL 추종 정책 60 Hz→ RaiSim 120 Hz

조작 기본 동작 (집기, 내려놓기 — 정책 하나 공유)

고정 참조 클립 1 개 (웅크림 → 일어섬, 팔 쉼 ↔ 운반 자세 선형 보간)+ 상자 상태 · 받침 위치 · 집기/내려놓기 원-핫→ 조작 RL 정책→ τ = kp(q̄ ⊖ q) − kd q̇ + τ_a

전환

이동 끝에 서기 자세 30–60 프레임 추가→ 조작→ 서기 자세 30–60 프레임 동안 a = (1 − λ) a_manip + λ a_loco, λ: 0 → 1→ 이동
  • 계층 사이에 되먹임이 없다. 확산 모델은 하위 정책의 실제 상태를 보지 않고 궤적을 만든다 (p.15).
  • 확산 모델과 RL 정책은 따로 학습했는데도 확산 궤적을 추종 가능 (p.11).

3. 관측과 행동

정책 입력

정책입력출처
걷기캐릭터: 루트 높이 p_z, 국소 좌표 루트 선·각속도, 관절 방향 q(쿼터니언), 관절 속도 q̇. 참조: 다음 프레임과의 루트 위치 차 t̄ − t_p, 루트 방향 차 t̄_d ⊖ t_d, 관절 방향 차 q̄ ⊖ q (모두 캐릭터 국소 좌표)p.7
걷기-나르기걷기 입력 + 캐릭터 좌표계 상자 위치·방향p.8
집기·내려놓기걷기 입력 + 바닥 상자가 놓인 받침 위치 + 집기/내려놓기 원-핫 (+ 걷기-나르기의 상자 입력으로 읽힘)p.9

행동

  • PD + 토크 혼합: τ = kp(q̄_{t+1} ⊖ q) − kd q̇ + τ_a. τ_a 가 정책 출력(보정 토크), q̄_{t+1} 은 참조 (p.8). kp, kd 값은 논문에 없음.
  • τ_a 가 고주파로 흔들려 발목 떨림·발 미끄럼이 생겨, 시뮬에서 이동 평균을 씀: τ^a_{t+1} = 0.3 τ^a_t + 0.7 τ^a (새 출력 70 %) (p.8).
  • 망: 층별 전문가 혼합(layer-wise MoE, [Xie 2022]). 크기는 논문에 없음 (p.7).
  • 캐릭터: Scadiver 각색 59 자유도(부유 기저 포함), SPD 제어기 (p.10).

확산 모델 표현

  • 조건 c = {경유점 2 개의 루트 위치 c_p ∈ R³, 방향 c_d ∈ R⁶ (회전 행렬 앞 두 열)} (p.5).
  • 프레임 = {출발 기준 루트 궤적 t_p ∈ R³, t_d ∈ R⁶; 다음 목표 기준 루트 궤적 t̃_p, t̃_d; 관절각 q ∈ R^{6M}} (p.5).
  • 경유점 2 개 → 2N 프레임, N = 15, 경유점 간격 0.5 s (p.6). 양방향 루트: λ{t} + (1 − λ){t̃}, λ 는 경유점에 다가가며 0 으로 선형 감소. 연속성은 다음 조각의 첫 경유점 = 앞 조각의 둘째 경유점으로 강제 (p.6–7).

초기화 · 무작위화 · 종료

  • 걷기: 데이터에서 동작 하나를 뽑아 첫 프레임 상태로 시작 (p.8).
  • 걷기-나르기: 상자를 캐릭터 바로 앞 두 손 사이에 놓고 시작. 상자 개수 무작위 (p.8).
  • 집기·내려놓기: 무작위 높이 받침 위 상자 앞에서 시작해, 같은 받침에 집기와 내려놓기를 반복 (p.9). 두 과제를 함께 학습하면 다양한 상대 상태를 겪어 일반화에 유리하다고 설명.
  • 학습 분포: 받침 앞뒤 0.35–0.40 m, 좌우 −0.10–0.10 m, 높이 0.3–0.7 m, 상자 1.0 kg, 폭 0.3–0.5 m (표 1). 걷기-나르기: 1.0 kg, 폭 0.3–0.5 m, 투사체 없음 (표 2).
  • 종료 조건: 논문에 없음. 커리큘럼: 언급 없음.

10. 한계

  • 저자 언급: 계획기·확산 모델·하위 제어기 사이에 되먹임이 없어 외란에 약함. 루트 추종 오차로 충돌·도착 실패. 기본 동작 순서를 미리 줘야 하고 전환 전에 서기 자세가 필요. A* 로는 옆걸음·뒷걸음 같은 자연스러운 발 순서가 어려움 (p.15–16).
  • 저자 언급: 무거운 상자는 손가락으로 바닥을 감싸거나 손잡이를 잡아야 하고, 몸 전체로 받쳐야 할 것 (p.16). 손가락 없는 두 손 옆면 방식의 무게 한계를 저자도 인정.
  • 우리 관점: 캐릭터 몸(59 자유도, SPD, 토크 한계 언급 없음)이라 8 kg 같은 숫자는 로봇에 옮길 수 없다. 성공률이 아니라 "3 회 이상" 극값만 있음. 종료 조건·망 크기·PPO 설정이 없음.

11. 우리에게 가져올 것

  1. 명목 "웅크림 → 일어섬" 일정 하나 + RL 보정. 참조 하나로 학습 높이 0.3–0.7 m 에서 0.05–1.00 m 까지 덮었다 (표 1). 우리 상위 출력을 "단계(시간) 함수인 명목 골반 높이·pitch + 명목 팔 자세(쉼 → 조이기 직전 선형 보간)"에 작은 잔차를 더하는 꼴로 정의하면, 처음부터 dev12 가 따라갈 수 있는 명령만 나오고 켜짐/꺼짐 포화도 줄어든다 (우리 적용안). 명목 일정은 dev12 도달 영역(서기 높이 0.335–0.77 m, pitch −45°–45°) 안에서 잡는다.
  2. 상자 높이 일정 보상. r = exp(−k (λ h_end + (1 − λ) h_begin − b_z)²), λ 를 들기 구간에서 0 → 1. h_begin = 받침 높이(0/0.1/0.2/0.3 m), h_end = 우리 유지 높이. 단 이 논문의 k = 10 은 오차 0.1 m 에서 0.90, 0.3 m 에서 0.41 이라 꽤 평평하다. 우리 들기 거리(수십 cm)에선 k 를 키울지 확인 (계산).
  3. 두 손 목표를 한 exp 안에, 단 배율을 붙여서. 이 논문 r_box-hand 는 배율이 1 이라 두 손 오차가 각 0.1 m 여도 exp(−0.02) = 0.98, 0.2 m 여도 0.92 로 기울기가 거의 없다 (계산). 우리는 exp(−k(d_L² + d_R²)) 에 k = 20–50 m⁻² 정도(0.1 m 씩이면 0.67–0.37)를 출발점으로 잡는다 (우리 적용안). 곱 꼴이라 한 손 밀기 해를 덜 보상한다. 목표점은 "반대 옆면의 미리 정한 점"이며 논문은 면 중심이라고는 쓰지 않았다.
  4. 조작 항은 명목 추종 항에 곱하지 말고 더하기. 조작 정책은 r_base 를 곱하지 않아 참조에서 벗어나 상자를 잡을 여지를 줬다 (p.10). 우리도 명목 자세 추종 항이 있다면 작게, 그리고 덧셈으로.
  5. 출력 이동 평균 + 매끄러움 보상. 새 출력 70 % 섞기(τ_{t+1} = 0.3 τ_t + 0.7 τ_new)와 exp(−‖Δ‖²) 보상 (p.8). 우리 상위 출력에도 환경 쪽 1 차 필터는 걸 수 있다(자르기가 아니라 PPO std 문제를 만들지 않음). 다만 범위 제한은 별도로 유계 분포로 해야 한다.
  6. 집기와 내려놓기를 한 정책으로 번갈아 학습. 같은 받침에서 반복하며 상태 다양성을 얻었다 (p.9). 나중 "내려놓기"를 붙일 때 별도 정책 대신 원-핫 하나로 같이 학습할 근거.
  7. 상자 직립 보상 exp(−10 ‖·‖²) 은 그대로 써도 무리 없다.

가져오지 말 것

  • A* + 확산 모델 동작 생성: 우리 접근·운반은 dev12 골반 명령으로 한다. 나중에 경로가 필요해도 루트 추종 오차(10 s 에 0.5 m)를 보면 되먹임 없는 개루프는 피할 것.
  • 보정 토크 행동: 우리 하위는 관절 위치 목표와 골반 명령을 받는다.
  • 일반화 숫자(8 kg, 0.05–1.00 m)를 K1 기대치로 삼기: 캐릭터 몸과 SPD 는 K1 팔 kp 22.3·고무 공 손 마찰 한계를 반영하지 않는다.
  • layer-wise MoE 망: 우리 과제 하나엔 MLP 로 충분하다.
