1. 문제와 과제

  • 문제: 오프라인 시연으로 학습한 DP 계획기는 하위 제어기와 따로 학습되어 (1) 명령 추종이 나쁘고 (2) 분포 이동·오차 누적으로 장기 과제가 실패한다. 시연을 늘리는 해법은 휴머노이드에서 너무 비싸다 (p.1).
  • 주장: 시뮬레이션에서 RL 로 DP 를 미세조정(RLFT)하면 희소 보상만으로도 성공률이 크게 오르고, 하위 제어기까지 함께 갱신하면 "계획기가 내는 움직이는 명령"이 하위의 학습 분포 안으로 들어와 추종이 좋아진다 (p.1–2, p.5).
  • 하위 동결의 부작용을 수치로 보임: DP 만 미세조정하면 DP 가 "excessive commands"(과한 명령)를 내도록 배워 추종 정확도가 떨어지고 큰 힘·접촉 변화 때 거친 움직임이 생긴다 (p.7, 그림 5).

세 단계: (a) 동결 하위로 시연 수집 → (b) DP 사전학습 → (c) 목표 환경에서 DP 와 하위 공동 최적화 (그림 1, p.2–3).

미세조정 커리큘럼 (OOD 초기 위치)

  • 로봇 초기 위치를 물체 기준 (i) 거리, (ii) 극각, (iii) 로봇 heading 으로 매개화. 미세조정 범위 = 사전학습 범위의 320 % / 125 % / 600 % (p.7). 그림 10 축: 거리 0.40–0.90 m(분포 안) → 2.00 m, heading ±30°(분포 안) → 180° (p.10).
  • 규칙: 현재 범위에서 성공률 90 % 에 닿으면 무작위 범위를 10 % 넓힘 (p.10).
  • 최대 범위에서 사전학습 정책 0 % → 커리큘럼 미세조정 80 % 이상 (p.7).
  • 커리큘럼 없이 최대 범위로 바로 학습해도 성공률은 오르지만, 초기의 큰 무작위에서 PPO 확률 행동이 증폭돼 OOD 구역 팔 jerk 가 사전학습 수준으로 높다. 커리큘럼 쪽은 모든 구역에서 jerk 가 안정 (그림 10(b), p.10–11).

기준선 구성 (p.6)

  • 모든 기준선은 같은 동결 πloco_manip 사용.
  • MLP-FT: 결정적 MLP 출력을 평균으로 보고 OU 식으로 확률화. Ak−1 = (1 − λk)Ak + λkμ̃θ(St) + σ̃kεk, λk 선형, σ̃k 감소 일정.
  • 하위 std 로 탐색하면 실패: 계획기 대신 πloco_manip 의 표준편차로 탐색하면 관절 수준 잡음이 너무 커서 과제를 못 끝내고 성공 신호가 0 (p.6).
  • Residual RL: 동결 DP 출력에 가우시안 잔차 정책(PPO)이 작은 보정을 더함.
  • Pure RL(무작위 초기화 + 희소 보상): 개선이 거의 없음, 수치는 논문에 없음 (p.7).

6. teacher → student / 증류

해당 없음 — teacher–student 증류가 없다. DP 는 처음부터 물체 자세(상태) 입력이고, 실기에서는 머리 D435i RGB + AprilTag 로 같은 물체 자세를 채운다 (p.5). 저자들도 RGB 조건 DP 를 향후 과제로 남김 (p.8).

10. 한계

  • DP 가 상태 조건이라 물체 자세가 명시적으로 필요(모캡 또는 마커) (p.8).
  • VR 텔레옵 + 과제별 휴리스틱 계획기에 기대는 데이터 수집 (p.8).
  • 실기 성공률 50–75 % 로 시뮬 90 % 이상과 격차, 매우 느린 속도 상한(0.2 m/s, 0.05 m/s) (p.7).
  • 재현에 필요한 값이 빠짐: 과제 보상 식, 종료 조건, 망 크기, PPO·DPPO 초매개변수, K, 무작위화 범위, 커리큘럼 일정, 행동 차원. 관측·보상 일부는 웹사이트로 미룸 (p.4).
  • 그림 5 에 분산 없음, "+18 %" 의 기준(절대·상대) 불명, 학습 시간 합이 서로 맞지 않음 (p.5, p.7).
  • 공동 최적화 L = 2 회뿐이라 더 길게 돌렸을 때 하위가 원래 명령 분포를 잊는지는 보이지 않음(논문에 없음).

11. 우리에게 가져올 것

  1. dev12 추종 오차를 상위 학습 내내 기록: teacher 가 낸 명령에서의 골반 높이 오차, vx·vy·ωz 오차, pitch 오차, 상체 11 관절 추종 오차를 dev12 자체 명령 분포에서의 값과 나란히 로그. REFINE-DP 에서 하위 동결 + 상위만 미세조정하면 손 위치 오차가 4 과제 모두 커졌다(예: Task 3 2.5 → 2.8 cm, 그림 5). v2 의 "추종기가 못 따라가는 출력"과 같은 현상을 숫자로 먼저 잡는다.
  2. 하위를 고칠 때는 Alg. 1 식 교대: (1) teacher 를 고정하고 그 명령으로 롤아웃 → dev12 를 원래 추종·AMP·정규화 보상으로 PPO 갱신, (2) dev12 를 고정하고 teacher 를 과제 보상으로 갱신, 이것을 2 회 정도 반복. 근거: 하위만 갱신해도 Task 2 +18 %, 이후 상위 90 % 도달 40 → 20 반복 (p.7). 과제 보상을 하위에 넣지 않는 점이 핵심.
  3. 탐색은 상위 명령 수준에서, 하위는 평균 행동으로: 하위 std 로 탐색하면 성공 신호가 0 이었다 (p.6). teacher 학습 중 dev12 는 확률 샘플이 아닌 결정적 평균 행동으로 돌리는지 확인.
  4. 손 목표 보상은 여러 폭의 exp 커널을 합친다: 손 위치 σ = 0.4 / 0.1 / 0.08 m 각 +2.0, 방향 σ = 0.8 / 0.5 / 0.3 각 +1.0 (표 III). 우리 "손 → 상자 옆면 중심" 접근 보상에 그대로 쓰면 먼 거리(0.3–0.5 m)에서도 기울기가 있고 마지막 몇 cm 에서 정밀도를 요구할 수 있다(추론). 양손 각각 따로 계산.
  5. 배치 범위 확장 커리큘럼: 고정 평가셋 성공률 90 % 마다 무작위 범위를 10 % 넓힘 (p.10). 우리 박스 범위(앞 0.04–0.30 m, 옆 ±0.15 m, yaw ±40°, 받침 0/0.1/0.2/0.3 m, 0.5–2 kg)를 좁은 중심에서 시작해 넓히면, 최대 범위로 바로 학습할 때 생기는 팔 jerk 증가를 피할 수 있다 (그림 10).
  6. dev12 의 "작은 거리 접근" 정밀도를 따로 잰다: 속도 추종 하체는 몸통 위치 3.8 ± 2.5 cm, yaw 10.6 ± 7.5° 오차(발 디딤은 1.2 cm, 5.1°) (그림 8). 상자 0.04–0.30 m 앞에서 두 손으로 37 cm 폭을 조이려면 몇 cm 가 중요하므로, dev12 에 PD 위치 되먹임으로 0.1–0.5 m 앞 목표에 서는 시험을 10 회 돌려 같은 지표로 비교. 저속 제자리걸음·지나침이 보이면 상위가 아니라 하위 문제로 분류.
  7. 실기 첫 배치는 느린 상한: 이동 0.2 m/s, 손 0.05 m/s 로 묶어 성공률을 올렸다 (p.7). 우리도 집기 단계 vx 상한을 낮게 두되, teacher 학습 분포에 같은 상한을 넣어 학습 밖 동작이 되지 않게 한다.

가져오지 말 것

  • 확산 정책 + DPPO 자체: 시연 50–1000 개와 사전학습 성공률 50–70 % 가 전제다 (p.7). 우리는 쪼그려 두 손 조이기 시연 수집 수단이 없고, teacher 를 밀집 보상 RL 로 처음부터 학습한다.
  • 희소 보상만으로 상위 학습: 무작위 초기화 + 희소 보상은 실패 (p.7). 우리 teacher 는 접근·두 손 접촉·들어올림 단계 보상이 필요.
  • 처음부터 공동 최적화: 이 논문도 DP 사전학습 뒤에만 함께 갱신했다. 우리 dev12 는 스모크 시험만 된 상태라, 먼저 동결 + 추종 오차 계측(1번)으로 문제가 보일 때만 2번을 쓴다.
  • 발 디딤 하체로 교체: 근거는 있지만(그림 8) dev12 는 속도 인터페이스로 이미 학습·동결 예정이다. 하위 재설계는 6번 측정 결과가 나쁠 때의 선택지로만 둔다.
  • 상태 입력에 일괄 가우시안 잡음: 생성형 DP 에서 σ 1–3 cm 잡음이 실기 70 % → 20–25 % 로 떨어뜨렸다 (p.11). 우리 student 는 가우시안 정책이라 그대로 적용되진 않지만, teacher 특권 상자 자세에 근거 없는 큰 잡음을 넣기보다 D436 실측 잡음 모형을 student 입력 쪽에 넣는 편이 맞다(추론).
  • 그리퍼 기반 쥐기·실패 유형: 그리퍼로 작은 물체를 잡는 설정이라 공 손 옆면 조이기의 미끄러짐·한 손 밀기 문제에는 정보가 없다.
