1. 문제와 과제

  • 문제: 선반 위부터 바닥까지 닿으려면 기저 위치·방향, 몸 높이·자세, 손 자세를 함께 써야 한다. 한 정책으로 처음부터 배우면 최적화가 어렵고 sim2real 이 나쁘다(p.1–2).
  • 기존 방법의 비용: AMO 는 궤적 최적화 안내, HOMIE 는 복잡한 보상·커리큘럼에 기대고, 둘 다 기본 명령 공간에서 텔레옵 시연을 모아 IL 한다(p.2–3).
  • 제안: 실기 검증된 기본 기술을 먼저 따로 만들고, 이들을 하나의 연속 잠재 공간으로 묶은 뒤, 과제별 상위 RL 이 그 공간에서 표집한다. 사람 시연은 쓰지 않는다(p.2–3, 표 1).

2. 시스템 구조

1단계 — 기본 기술 학습 (부위별 PPO, 나머지 관절 고정)

보행 πloco: ⟨vx, vy, ω⟩ → 하체 PD 목표 몸 자세 πbody: ⟨h, b⟩ → 하체 PD 목표 손 도달 πhand: ⟨6D 손 끝 자세⟩ → 두 팔 PD 목표

2단계 — 이종 기술 앙상블 (CVAE student 학습)

teacher: 하체 πloco 또는 πbody + 상체 πhand (동결) → a* = concat(alower, aupper) → DAgger 손실 → student: 인코더 E(z|s, g) · 학습 사전 P(z|s) · 디코더 D(a|s, z) ← PPO 손실(두 teacher 보상 합) ← 시뮬: 부위별 명령 동시 + 에피소드 중 하체 기술 전환

3단계 — 과제별 상위 정책 (실행 시 흐름)

과제 목표 ghigh (점·상자) + 상태 shigh → 상위 πplan (PPO 학습) → 잠재 zt → 디코더 D(a|s, z) (동결) → 전신 관절 PD 목표 → 로봇 / 시뮬

그림 2(p.4) 를 다시 그림. 점선 = 동결.

앙상블 student (p.5)

  • 입력: 상태 st + 목표 gt. gt 에는 하체·상체 기술 명령과 어느 teacher 가 활성인지 알리는 기술 지시자가 들어간다.
  • 출력: 전신 관절 행동 at. 정답은 두 teacher 행동을 이은 a* = concat(alower, aupper) (식 7).
  • CVAE: 인코더 E(z|s, g) = N(μe, σe), 디코더 D(a|s, z), 학습되는 조건부 사전 P(z|s) = N(μp, σp). 고정 단봉 가우시안 대신 상태별 분포를 잡는다(p.5).

상위 πplan (p.5)

  • 입력: splant, 과제 목표 gplant(점 위치, 상자 등). 구체 구성 논문에 없음.
  • 출력: 잠재 zt(차원 논문에 없음) → 동결 D → 관절 행동.

6. teacher → student / 증류

여기서 증류는 지각 증류가 아니라 기술 teacher 여럿 → CVAE student 하나다(이종 기술 앙상블, p.4–5). student 와 teacher 는 같은 고유감각을 본다.

왜 기본 기술을 그냥 이어 쓰면 안 되나 (p.4–5)

  • 조정·전환이 분포 밖: 따로 학습해서 "쪼그리며 팔 뻗기", "보행 → 몸 자세 전환"을 본 적이 없다. 부위별 행동을 이어 붙이거나 기술을 바꾸면 불안정하거나 넘어진다.
  • 명령 공간이 서로 다름: 상위가 모든 명령을 동시에 내면 충돌(예: 빨리 걸으며 아주 낮게 쪼그리기). 기술 지시자 + 해당 명령을 내게 하면 "이산 지시자가 RL 탐색을 막고 상위가 한 기술만 고집"했다.

앙상블 학습 절차 (p.5)

  1. 환경: 매 스텝 teacher 둘이 활성: 하체 πlower ∈ {πloco, πbody}, 상체 πupper = πhand. 부위별 목표를 동시에 준다(걸으면서 손 6D 추종 = 조정). 에피소드 중 하체 기술을 무작위로 바꾼다(πlowert+1 ≠ πlowert = 전환).
  2. IL: LDAgger = E ‖aensemt − a*t‖² (식 7). student 가 굴리고 teacher 가 정답을 단다.
  3. RL: LPPO 는 두 teacher 의 보상을 합친 보상. 추가 항 없이 조정·전환을 배운다.
  4. 혼합: LEnsem = λ1LDAgger + λ2LPPO, λ1 0.95 → 0.05 (식 6). 처음엔 모방, 나중엔 탐색. teacher 감독을 끝까지 유지해 망각을 막는다.
  5. 잠재 정리: LRegu = ‖μe(st, gt) − μe(st+1, gt+1)‖ (식 9) 로 이웃 시점 잠재를 붙여 전환이 잠재 공간에서 연속이 되게 하고, LKL = DKL(E ‖ P) 로 사후를 학습 사전에 묶는다(식 8).

순차 IL → RL 과의 차이 (그림 4, 표 4, p.7)

  • 순차(Seq-ILRL): IL 사전학습 뒤 RL 만. 약 5k 반복에서 RL 을 켜자 정규화 명령 추종 정확도가 약 0.6 → 0.3 으로 무너지고 회복 못 함. "처음부터 학습보다도 나쁘다"(그림 읽기, p.7).
  • 동시(R2S2): 약 0.7 까지 오르고 유지. IL 만(w/o SE) 은 약 0.6 에서 정체. 기본 기술 없이 처음부터(w/o PS) 는 15k 에서 약 0.6(그림 읽기).

11. 우리에게 가져올 것

  1. 상위 행동은 연속 명령만, 이산 모드 플래그 금지(p.5: 이산 지시자가 탐색을 막고 한 기술만 고집). "쪼그림 모드 / 걷기 모드" 같은 이산 출력을 teacher 행동에 넣지 않는다. dev10 v2 의 on/off 포화 출력과 같은 계열의 실패다.
  2. 명령 충돌은 상위 행동 변환에서 미리 막기: R2S2 가 든 충돌 예("빨리 걸으며 아주 낮게")가 dev12 에는 범위로 이미 있다(걷기 높이 0.42 m 하한, roll 은 서기만). teacher 행동 → dev12 명령 변환에서 속도가 0 이 아닐 때 높이 하한 0.42 m, roll 0 을 강제하고, 자른 만큼 원 행동 L2 벌점(std 폭주 교훈).
  3. 상자 과제 보상의 최소 골격(표 2): "손 → 상자 옆면 거리" + "상자 높이 → 목표 높이" 두 항, 각 1.0. 우리 teacher 의 뼈대로 두고 조임·두 손 접촉 항을 위에 얹는다. 단 exp(−d) 는 m 단위 스케일 1 이라 d = 0.05 m 에서 0.95, 0.30 m 에서 0.74 로 너무 평평하다. 커널 폭은 우리 거리(수 cm–30 cm)에 맞게 따로 정할 것(예: exp(−d/0.1), 값은 우리 결정).
  4. 정규화 묶음을 시작값으로(표 2): 행동 변화율 −0.01, 행동 가속(2 차 차분) −0.01, 원치 않는 충돌 −5.0, 기본 자세 exp(−2|q − q0|²) 0.2. 상위 행동(골반 명령 6 + 상체 11)에 걸고, q0 는 상체 11 의 "두 손 앞으로" 기본 자세로.
  5. student 증류에 DAgger + 같은 과제 보상 PPO 를 동시에(식 6): λ1 을 0.95 에서 줄여 가고 λ2 를 올린다. 순차 IL → RL 은 RL 시작 직후 추종 0.6 → 0.3, 상자 29.53 % 로 무너졌다(그림 4, 표 4). dev10 v2 student 격차(Isaac 69 % vs teacher 90 %)를 줄일 후보: 깊이 student 가 자기 관측으로 못 따라 하는 부분(접촉 정보)을 RL 로 메우되 teacher 감독은 끝까지 유지. 최종 λ1 을 0.05 까지 내릴지는 시험으로 정할 것(R2S2 student 는 teacher 와 같은 관측을 봄).
  6. dev12 동결 전 "조정·전환" 점검(p.4–5): R2S2 는 따로 배운 기술을 이으면 넘어진다고 보고하고, 부위별 명령 동시 송신 + 에피소드 중 기술 전환으로 해결했다. dev12 스모크에 (a) 걷는 중 상체 11 목표의 빠른 변화와 0–5 kg 손 하중, (b) 서기 영역(높이 0.335–0.42 m, pitch, roll) ↔ 걷기 영역 전환을 에피소드 중간에 넣어 추종 오차·넘어짐을 잰다.
  7. 쪼그림 안정 점검 항목(표 2, p.4): 두 발 동시 접지 cleft·cright(1.0), 기저 roll exp(−4r²)(1.0), 다리 토크 대칭(−0.2). 상위 학습 중 dev12 가 낮은 높이·큰 pitch 에서 한 발 들림이나 좌우 토크 비대칭을 보이면 여기서 원인을 찾는다(고칠 땐 dev12 쪽에서).
  8. 평가 꼴(p.6): 성공률과 거리 오차를 같이 보고, 성공 문턱은 목표보다 약간 아래(1.4 m 목표에 1.3 m). 우리 고정 평가셋에서도 성공률 + "상자 높이 목표까지 남은 거리" + 양손–옆면 거리를 같이 기록.
  9. 잠재 행동 공간은 "다음 수"로 보관: 명시 명령 상위가 탐색에서 막히면(43.29 % → 100 % 근거), dev12 를 그대로 두고 상위 위에 저차원 행동 사전(예: 상체 11 + 골반 명령을 IK 기준 자세로 묶은 잠재)을 두는 선택지를 검토.

가져오지 말 것

  • 하위를 CVAE 잠재 디코더로 갈아타기: 하위를 기술 teacher 들로부터 DAgger + PPO 로 다시 학습해야 한다. dev12 는 MLP 명령 추종 정책이고 팔은 하위 밖이다. z 는 해석이 안 돼 dev12 범위 자르기·추종 오차 감시도 못 한다.
  • 6D 손 끝 자세 명령: K1 팔은 5 자유도라 임의 6D 자세를 못 만든다. 상체는 관절 목표로 둔다.
  • 실기 90 % 를 기대치로: 상자·목표 상태를 모션 캡처로 받은 숫자다. 우리 student 는 D436 깊이로 상자를 본다.
  • w/o LS 43.29 % 를 "명령 공간 상위는 안 된다"로 읽기: 그 기준선은 이산 지시자 + 부위별로 다른 명령 공간 + MLP student 의 묶음이다. 연속 통합 명령인 dev12 와 같은 조건이 아니다.
  • 상자 목표 1.4 m(머리 위)·받침 0.2–1.2 m 분포: 우리는 바닥·0.3 m 이하에서 집어 서서 유지한다. 과제 분포를 그대로 쓰면 바닥 도달 한계 문제를 피해 간다.
  • Vanilla PPO 0 % 를 우리 상황의 근거로: 하위 없이 관절을 처음부터 배우는 PPO 다. 동결 하위 위 상위 PPO 와 다르다.
  • 보행 주기 보상(Von Mises): 하위 보행 학습용이다. dev12 는 AMP 로 걷고 동결한다.
