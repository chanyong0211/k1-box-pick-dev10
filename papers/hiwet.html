1. 문제와 과제

  • 문제의식: 기존 명령 기반 방법은 손 목표를 몸 기준 좌표로 준다. 다리로 걸으면 기저가 누적해 흘러가고 고주파로 흔들려, 세계 좌표에서 손 정밀도가 떨어진다(p.1–2).
  • 재정의: 과제를 "세계 좌표 손 끝 추종"으로 놓으면, 목표가 정적 도달 범위 밖일 때 기저를 옮기고 높이를 바꿔 작업 공간을 다시 만드는 일이 정책 안으로 들어온다(p.2).
  • 계층: "어디로 갈지"(상위, 세계 좌표)와 "어떻게 움직일지"(하위, 동역학 안정)를 나눈다. Semi-MDP 로 정식화, M = ⟨S, AH, AL, P, R, γ⟩(식 1). 상위 πH 는 K 스텝마다, 하위 πL 는 매 제어 스텝 실행(p.2).
  • 평가 과제: 하위 단독 명령 추종(표 1), 상위의 기하 궤적 5 종 추종, 8 방향 5 m 기저 재배치, KMP 대 최적화 IK 비교, 실기(p.6–8).
  • 다루지 않는 것: 접촉이 많은 조작(쥐기 등)은 미탐구, 상위 실험은 한 팔만(p.9).

커리큘럼·명령 분포

  • 상위 공간 커리큘럼(식 17, p.5): 처음엔 현재 기저 근처에서 세계 목표를 뽑고, 손 오차 eee = ‖wT − wT*‖ 가 문턱 εth 아래면 평면 범위를 Rk+1 = Rk + ΔR·𝟙[eee < εth] 로 넓힌다. 초기 R, ΔR, εth 는 논문에 없음. 최종 평가 범위는 ±5 m(p.7).
  • 하위 명령 중요도 표집(식 10, p.4): c ∼ β·puniform + (1 − β)·pprior. pprior = IK 실패(재구성 오차 큼)로 걸러내고 manipulability 로 가중한 손 자세 데이터셋 + 작은 섭동, puniform = 전체 직교 부피 균등. β 값은 논문에 없음.
  • α: 학습 내내 균등 [0.1, 10](p.3).

11. 우리에게 가져올 것

  1. 상위 학습 내내 dev12 를 완전 동결하고, 상위 행동 = 하위 명령 공간 그대로. HiWET 은 이 꼴로 PPO 상위가 학습됨을 보였다(p.5). 우리 행동: 골반 vx·vy·ωz·높이·pitch·roll + 상체 11. 범위는 dev12 학습 범위 안으로 자르되, 자른 만큼 원 행동 L2 벌점을 같이 둘 것(dev10 v2 의 std 폭주 교훈).
  2. 비대칭 critic 에 참값 넣기(식 15): HiWET critic = 참 기저 속도 + 세계 손 자세. 우리 teacher critic 에는 참 골반 속도, 박스 자세·속도, 손–박스 접촉력, dev12 추종 오차를 넣고, actor 에는 student 가 깊이·고유감각으로 재구성할 수 있는 것만 둔다.
  3. 팔 기준 + 잔차 행동(식 5, 표 1: KMP 없으면 손 오차 12.4 → 25.2 mm, 분산 5 배): teacher 상체 행동을 "박스 옆면 두 손바닥 IK 기준 + 작은 잔차"로. 기준은 박스 자세(특권)로 손바닥 목표를 옆면 중심 ± 조임 여유로 두고 K1 5 자유도 팔 IK(위치 + 손바닥 법선만)로 푼다. 한 손 밀기 국소 최적과 on/off 포화 출력을 줄이는 쪽. 단, student 는 기준을 못 계산하므로 최종 관절 목표를 증류 대상으로 할 것.
  4. 기준 추종 보상은 exp 꼴 + 명령 바뀐 직후 약하게(식 11): r = exp(−‖qup − q̂up‖² / (N σ²)), 단계(접근→조이기→들기)가 바뀐 직후 몇 스텝은 스케일을 낮춰 과도 응답을 묶지 않는다. σ 는 우리가 정할 값(논문에 없음).
  5. 공간 커리큘럼(식 17): 성공 기준을 넘으면 범위를 한 칸씩 넓힌다. 우리 축: 받침대 0.3 → 0.2 → 0.1 → 0 m, 발끝 앞 거리 0.04–0.30 m, 옆 ±0.15 m, yaw ±40°. 쉬운 0.3 m 받침대·정면·yaw 0 에서 시작. 문턱은 고정 평가셋 성공률로(값은 우리가 정함).
  6. 가능 영역 중요도 표집(식 10): 박스 배치를 β·균등 + (1 − β)·"K1 이 실제로 닿는 배치"로 섞는다. dev10 v2 에서 본 바닥 박스 도달 한계처럼 불가능한 배치는 미리 IK 로 걸러, teacher 가 불가능 과제에 탐색을 낭비하지 않게 한다. 균등 몫은 남겨 경계 사례를 본다.
  7. 평가 표 꼴(표 1): 상위 학습 전후로 dev12 의 선속도·각속도·높이 오차를 같은 표로 잰다. 참고 수준: G1 HiWET 0.157 m/s, 0.461 rad/s, 0.018 m. "팔 기준을 세게 걸면 기저 추종이 조금 나빠지는" 맞바꿈(w/o KMP 쪽이 기저 오차가 더 작음)도 같이 본다.
  8. 나중 접근 단계용 보상(p.5): 골반–박스 평면 거리 벌점 + 골반 heading 과 명령 속도가 박스 중심을 향하는 정렬 보상. 집기 과제에는 쓰지 않고, 다가가 집기·운반 단계에서.

가져오지 말 것

  • 손 SE(3) 자세 명령 인터페이스로 바꾸기: dev12 는 상체 관절 목표를 관측하도록 학습돼 인터페이스를 바꾸면 하위를 다시 학습해야 한다. 또 K1 팔은 5 자유도라 임의 6 자유도 손 자세를 못 만든다.
  • 세계 좌표 목표 + LiDAR 위치: K1 에 LiDAR 가 없고, 집기는 몸 기준 박스 위치(깊이)로 충분하다. 세계 좌표는 긴 운반 경로에서나 의미가 있다.
  • 허리 가중 α: G1 허리 3 자유도로 CoM 을 옮기는 장치다. K1 허리는 yaw 1 개뿐이고 앞뒤 CoM 은 dev12 골반 pitch 명령이 맡는다.
  • 12.4 mm 정밀도를 목표치로 삼기: 물체·하중·접촉 없는 자유 공간 추종 수치다. 우리 성공은 조이기 접촉과 들기 유지로 재야 한다.
  • 보상 가중치: 논문에 없어 가져올 값이 없다. 무릎 인지 높이 항(식 12)은 하위 보상이라 동결 dev12 에는 해당 없음.
  • 비활성 팔 중립 벌점: 우리는 두 손을 항상 쓴다.
