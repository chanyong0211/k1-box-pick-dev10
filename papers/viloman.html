1. 문제와 과제

  • 목표: 다가가기 → 자세 잡기 → 문 닫기까지 긴 과제를 정책 하나가 닫힌 루프로 수행. 배포 시 입력은 머리 깊이 + 고유감각뿐, 참조 모션·중간 명령 없음 (p.1–3)
  • 두 난점: ① 물리적으로 실행 가능한 로봇–물체 데이터 부족 (사람 모캡은 상호작용 구간만 있고 다가가기가 없음) ② 시각에서 전신 관절로 바로 배우기 어려움 (p.1)
  • 성공 정의: 생존 (조기 종료 없이 평가 구간 끝까지) 그리고 끝에서 문 열림 각 < 10°. 생존과 성공을 따로 보고해 넘어짐과 과제 실패를 구분 (p.5 IV-A)
  • 평가: 학습 409 / 테스트 106 궤적 (TRUMANS 원본 클립 단위로 분리), 궤적마다 DR 을 독립 표본한 5 회 시행 (p.5)
  • 조기 종료 조건·에피소드 길이: 논문에 없음

2. 시스템 구조

세 단계: 데이터 만들기 → 참조 조건 teacher → 참조 없는 시각 student. 제어는 모두 50 Hz, 물리 0.005 s (제어 1 스텝 = 물리 4 스텝) (p.3, 표 VII).

① 데이터 (p.3 III-B)

TRUMANS 사람–문 모캡 (SMPL-X)→ OmniRetarget (상호작용 보존 리타겟) → 상호작용 구간 71 개→ Kimodo 다가가기 생성 × 10 → 710 궤적→ DoorGym 문 무작위 (손잡이·경첩·각·크기)→ 궤적마다 추종 정책 학습해 물리 정제→ 거르기 → 학습 409 / 테스트 106

② teacher (PPO, 모션 군집마다 specialist 하나) (p.4 III-C, 식 1–2)

③ student (온라인 DAgger, 배포) (p.4 III-D, p.9 B)

6. teacher → student / 증류

  • 왜 온라인 DAgger: 오프라인 BC 는 공변량 이동으로 시연 밖 상태에 빠진다. student 가 방문한 상태 ξt ∼ dπStudent 에서 같은 시뮬 상태로 student·teacher 관측을 만들고 teacher 행동을 라벨로 쓴다 (p.4, 식 4).
  • 롤아웃은 student 만: teacher 롤아웃을 섞는 비율 (β, α) 언급이 없다 (식 4).
  • 손실: 차원별로 정규화한 student·teacher 행동의 제곱 오차 L = E‖ãstudent − ãteacher‖² (식 5).
  • 리플레이: 미니배치 분포 μ = 현재 배치 2/3 + 갱신 전 리플레이 1/3. 현재 배치는 student 갱신 뒤에 유한 리플레이에 들어간다 (p.4).
  • teacher 가 여러 specialist: 어느 상태에 어느 specialist 가 라벨을 다는지 (궤적 군집 기준으로 보임)는 논문에 없음.

10. 한계

  • 과제 하나: 문 닫기만, 문 폭 1.000 m 고정. 하중을 드는 과제가 아니라 손 힘·물체 질량 문제를 다루지 않는다 (표 IV).
  • 무거운 데이터 파이프라인: 사람 모캡 + 리타겟 + 생성 모델 + 궤적마다 정제 정책 + 군집별 specialist. 정제 정책·specialist 수와 학습 비용은 논문에 없음.
  • 보고 안 된 값: 반복 수·학습 시간·GPU, 조기 종료 조건, 행동 척도·PD 게인, 깊이 블러 세기, 잔차 CNN 구조, 실기 깊이 처리·지연.
  • 깊이 DR 이 블러뿐: 카메라 자세·지연·구멍 무작위 없음. 실패 사례도 깊이 대비 부족 쪽 (p.6, 표 VI).
  • 인터페이스 비교의 교란: SONIC 은 토큰 DAgger, Handoff 는 1 Hz VLM 플래너라 학습 방식이 다르다. 같은 RL·DAgger 로 학습한 작업 공간 상위 정책과의 비교는 없다 (추론).
  • 분포: 테스트의 오른쪽 경첩 비율 60.4 % 가 학습 33.3 % 보다 높음 (표 IV). 실기는 40 회, 문 종류 구성은 논문에 없음.
  • teacher 도 참조 의존: 단계가 참조 시간으로 정해져, 참조 없는 student 는 단계를 스스로 알아내야 한다 (p.9 C).

11. 우리에게 가져올 것

  1. DAgger 손실은 차원별 정규화 행동 MSE (식 5). 우리 출력은 상체 11 (rad)과 골반 6 (m/s, rad/s, m, rad)이 섞여, 정규화 없이 쓰면 큰 단위 차원이 손실을 지배한다. 정규화 통계는 teacher 행동 분포에서 잡는다.
  2. 리플레이 섞기를 그대로: 미니배치 2/3 현재 + 1/3 갱신 전 리플레이, 워커당 300,000 샘플 (float16), 1 epoch, 미니배치 1,024, AdamW 10−4, 32 스텝 (0.64 s) 조각을 리셋 없이 이어 감 (표 VII). v2 student 의 체크포인트별 성공 출렁임을 줄일 후보 (추론).
  3. DAgger env 수를 줄이지 말 것: 1/2 이면 테스트 −7.74 pp, 1/4 이면 −10.38 pp, 실기 32/40 → 27/40 (표 II, p.6). 깊이 렌더 비용 때문에 env 를 줄이고 싶어도 teacher 학습과 같은 급 (논문은 16,384) 유지.
  4. 성긴 고유감각 이력: 오프셋 [0, 1, 2, 3, 4, 8, 12, 16, 20] 스텝 (0.4 s) × (각속도 3, 중력 3, 관절 위치·속도) + 이전 행동 8 개 (p.9 B). K1 이면 9 × (3 + 3 + 23 + 23) + 8 × 17 = 604 차원 (계산). 팔 kp 22.3 이라 조이기 접촉이 팔 PD 추종 오차의 시간 변화로 드러나므로, 0.4 s 이력이 "접촉 정보" 격차를 일부 메울 수 있다 (추론).
  5. 단계 경계 리셋: 단계 0 / 1 / 2 에서 0.25 / 0.15 / 0.60, 가장 어려운 단계에 60 % (표 VII). 우리 단계 ① 접근·숙이기 ② 손을 옆면에 대기 ③ 조여 들고 일어서기 ④ 유지 중 ③④ 비중을 높이고, 시작 상태는 teacher 롤아웃 스냅샷으로 만든다 (참조 궤적이 없으므로). 바닥 박스 도달 단계를 더 자주 연습하게 된다 (추론).
  6. 손–표면 거리 보상 모양: 접촉 전 2·exp(−max(d − 0.06, 0)/0.18) (가중 1.0), 접촉 중 4·exp(−max(d − 0.04, 0)/0.12) (가중 2.8), 관통 −max(−0.02 − s, 0) (가중 0.45) (표 V). 우리 d = 손 공 중심 − 박스 옆면 거리 (손마다). 단 논문은 두 손 평균이라 한 손 밀기가 보상을 반은 받는다 → v2 한 손 밀기 국소 최적 대책으로 우리는 두 손 중 최소값 또는 곱을 쓴다 (추론).
  7. 진행 보상 + 최종 추적 쌍: clip(진행/목표 변화, 0, 1) 에 진행도 게이트 (가중 6.0), 끝 단계 지수 추적 + L1 벌점 (12 + 8) (표 V) → 박스 높이 진행 clip((zbox − z0)/(z목표 − z0), 0, 1) 과 "들고 유지" 단계의 높이 추적 + L1 로 옮긴다.
  8. 행동 규제 값: 잔차 크기 2×10−4, 잔차 변화 5×10−4, 전체 행동 변화 0.01, 초기 std 0.25, 엔트로피 0.0025 → 0.0005 지수 감소, 목표 KL 0.01, actor·critic 기울기 norm 각각 1.0 (표 V, VII). v2 의 std 폭주 (환경 안 자르기 + 무벌점)와 on/off 포화 대책으로 "자르기 대신 크기·변화 벌점 + 낮은 초기 std" 쪽 근거. 논문은 행동 자르기 여부를 말하지 않는다.
  9. 평가 규약: 고정 테스트 셋의 각 구성을 DR 독립 표본 5 회, 생존과 성공을 따로 보고 (p.5). 우리는 받침대 높이 4 × 거리 × 옆 × yaw 격자를 고정해 모든 체크포인트를 같은 셋으로 재 비단조 성공을 가린다.
  10. teacher 특권 정보는 깊이로 복원 가능한 것 위주: 이 논문 teacher 맥락 (단계·문 상태·접촉 목표)은 깊이에 보이고 접촉 항도 기하 거리뿐 → 격차 7.36 pp (표 II, p.9 E). v2 격차 21 pp 의 원인으로 본 손 접촉력·박스 질량은 teacher actor 에서 빼 critic 전용으로 (추론).
