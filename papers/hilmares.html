1. 문제와 과제

  • 문제: 다리로 조작하면서 계속 걸어야 하는 과제마다 따로 정책·보상을 만들면 일반화가 안 된다. 보행과 조작 계획을 분리해 각각 RL 로 풀자 (p.1–2).
  • 핵심 주장: 실기에서 검증된 저수준을 재사용하면 상위가 "동역학적으로 불가능한 행동"을 배우지 않고, 종단 학습보다 표본 효율이 크게 높다 (그림 2 설명, p.7).

2. 시스템 구조

과제 관측(상태 또는 깊이) + 기저 자세·각속도 + 위상 (sin φ, cos φ)→ 과제별 계획기 (학습)→ Bézier 제어점 + CPG 명령 (vx, vy, ωz)→ 발끝 목표 = CPG 명목 ξn(t) + Bézier 잔차 ξr(t)→ 보행 제어기 (고정, 50 Hz)→ 모터 위치 목표 → PD 1 kHz
  • CPG 명목 궤적: 발 4개의 3D 궤적을 고차 다항식으로, 매개 = 목표 기저 속도 vx·vy 와 yaw rate, 스윙 정점 높이. 진동자 매개를 고정해 트로트 하나만(주기 Tg 고정) (p.3).
  • Bézier 잔차: 스윙 다리마다 제어점 3개. 처음·끝 점의 z 를 0 으로 고정해 착지·이륙이 바닥에서 시작·끝나게 → 고르는 값은 P0, P2 ∈ R² (x, y), P1 ∈ R³. 시간은 스윙 시간 Tsw = Tg/2 로 [0, 1] 정규화. 디딤 다리는 그 자리 한 점. 좌표는 기저 footprint 프레임 (p.3).
  • 위상 공유: 상위도 같은 (sin φ, cos φ), φ = 2πt/Tg 를 받아 하위 보행 주기와 동기 (p.4).
  • 상위 실행 주기는 논문에 없음("각 timestep k").

4. 보상 · 종료 · 커리큘럼

  • 하위 보상: 가장 큰 가중치 = 발끝 추종 rtracking = exp(−σe‖xe,t − (ξn(t) + ξr(t))‖²) (네 발, 디딤발은 고정점). + 롤·피치 각속도 벌점, 수직 속도 벌점, yaw 위치 추종 (p.3). 가중치·σe 값 논문에 없음.
  • 과제 무작위화: Bézier·CPG 매개를 표 I 범위에서 균등 표본, 10 s 마다 새로 뽑음 (p.3).
  • 동역학 무작위화: 관절 PD 게인, 지면 마찰, 기저 질량, 무작위 밀기 — 범위는 GenLoco [23] 표 3 참조, 본문에 수치 없음 (p.3).
  • 에피소드: 4,000 스텝 = 80 s (p.3). 종료 조건 논문에 없음.
  • 커리큘럼: 논문에 없음.

8. 실기 · sim2real

  • 하위: 동역학 무작위화 + 4스텝 이력으로 zero-shot 이전.
  • 짐 밀기 base 실패 원인: 짐이 시뮬처럼 완전한 정육면체가 아님, 짐 가까이서 UWB 측위 잡음 → 빗나간 밀기, 크게 돌아가는 경로 (그림 4a).
  • 실데이터 학습 뒤: 먼저 자세를 맞추고 목표 방향으로 밀기, 놓치면 좁게 돌아 재시도 → 경로 단축 (그림 4b).
  • 드리블: 정확한 측정 시스템이 없어 보상이 잡음투성이 → 실데이터 학습은 못 함 (p.7).

10. 한계

  • 트로트 하나(고정 CPG 주기)만. 다른 보행·스텝 높이는 향후 과제 (p.7).
  • 다리로 하는 비파지 조작만 — 쥐기·들기 없음.
  • 하위 보상 가중치·σ, DR 범위, env 수, 상위 행동 범위·주기가 본문에 없다.
  • 기준선 비교가 8회 시도, 실기 성공률의 시도 수 미공개. 실데이터 학습에는 외부 측위(UWB)가 필요.

11. 우리에게 가져올 것

  1. "명목 + 작은 잔차"로 상체 탐색 공간 줄이기: HiLMa-Res 잔차는 명목 궤적 대비 x 3.5–7 cm, y ±10 cm, z ±5 cm 이내(표 I). 우리: 상체 11 = 단계별 명목 자세(접근 · 쪼그림 · 옆면 조이기 · 들기) + a · Δmax. Δmax 는 dev12 가 학습 중 본 상체 목표 변화(저역 필터 목표와 그 변화율) 범위 안에서 정한다.
  2. 상위 명령 공간 = 하위 학습 명령 공간: 하위는 표 I 범위를 10 s 마다 새로 뽑아 학습했다. 우리: 골반 명령을 dev12 학습 범위(vx ±0.8, vy ±0.4, ωz ±1.0, 높이 정지 0.335–0.77 · 보행 0.42–0.77, pitch ±45°, roll ±10° 정지만)로 자르고, 상위가 실제로 쓰는 조합(쪼그림 + pitch + 손 하중 동시)이 dev12 샘플러에서도 나오는지 확인한다. (논문은 상위 출력을 자른다고 명시하지 않음 — 이 항목은 추론.)
  3. 하위 실기 검증이 먼저: 이 틀의 전제는 "하위가 실기에서 평가된 뒤" 재사용하는 것이다(p.2). dev12 는 아직 스모크 시험뿐이므로, pelvis_pick 실기 시험 전에 dev12 단독으로 골반 명령 격자(높이 × pitch)와 손 하중 0–5 kg 추종을 실기에서 잰다.
  4. 위상 공유: dev12 가 보행 위상을 쓴다면 같은 (sin φ, cos φ) 를 상위 관측에도 넣는다(확인 필요).
  5. 깊이 직접 PPO 가 가능한 크기: 43×29 깊이 + 작은 CNN + GRU 64 로 증류 없이 5 시간. 우리 26×64 × 6 프레임과 크기가 비슷하다 — student 격차(Isaac 69 % vs teacher 90 %)를 줄이는 "student RL 미세조정" 실험의 근거 하나로 쓸 수 있다(과제 난이도는 다름).

가져오지 말 것

  • CPG·Bézier 발끝 궤적 인터페이스 자체: 사족 트로트용. 우리 하위 인터페이스는 골반 명령 + 상체 관절이다.
  • DroQ/RLPD 실기 학습: 사람이 리셋하고 외부 측위로 보상을 재야 한다. K1 박스 집기에서 지금 쓸 단계가 아니다(실기 실패가 반복될 때 후보).
  • 기준선 대비 수치(100 vs 0–62.5 %)를 일반화하지 말 것: 8회 시도, 기준선은 Gazebo 로 옮긴 sim-to-sim 결과.
