1. 문제와 과제

  • 정식화: 목표 조건부 POMDP. 매 스텝 관측 ot 와 과제 조건 ct 를 받아 PD 관절 목표 at 를 낸다 (p.3, III-A·B).
  • 목표 두 종류: (i) 조밀 참조 — 시간 색인된 동작 참조가 중간 동작까지 지정; (ii) 희소 목표 — 먼 미래의 루트·물체 변환만 주고 중간 동작은 정책이 정함 (p.3).
  • 지각 두 종류: (i) MoCap — 물체 자세 정확; (ii) 자기중심 깊이 — 머리 깊이 센서 점구름에서 물체 상태를 추론 (p.3).
  • 성공 정의
    • 추종: 넘어지지 않고 매 프레임 Eg-mpjpe < 0.3 m 이고 Epos < 0.3 m. "humanoid 만" 성공도 따로 보고 (p.6, V-C)
    • 목표 따르기: 넘어지지 않고 마지막 상태가 목표에서 0.3 m 이내 (p.6, V-D)
  • 데이터: OMOMO 사람-물체 모캡, InterMimic 이 정리한 부분집합. 고정 손으로 다룰 수 있는 상자류 4 물체만. RL 리타게팅 + 축별 궤적 배율·물체 크기 조정으로 약 6배 코퍼스. ID = 원래 train/test 분할, OOD = 보류 동작 + 처음 보는 물체 크기 (p.5, V-A).
  • 코드의 증강 예: --xyz 1 1 1, --xyz 1.05 1 0.95, 물체 자산 크기 080_080_080·100_100_100 (README.md).

3. 관측과 행동

3-1. 행동과 PD

  • 29 차원, rl_games 가 env 에 넣기 전 ±1 로 자름 (clip_actions 기본 True) (a2c_common.py).
  • PD 목표 = 3.0 × 행동 (rad, 기본 자세 오프셋 없이 절대값), 토크 = 모터 세기 × kp·(목표 − q) − 모터 세기 × kd·q̇, ±0.8 × effort 로 자름 (humanoid.py _compute_torques, humanoid_g1.py).
  • 행동 지연: 매 스텝 0 또는 1 정책 스텝 (17 ms) 을 무작위로 (모든 env 공통). 논문 표 I 의 "buffer length 8 steps" 는 버퍼 길이일 뿐 (humanoid.py pre_physics_step).

4-3. 종료와 초기화

  • teacher 종료 (시작 20 스텝 뒤부터): 루트 높이 < 0.15 m; 어느 몸체든 참조에서 0.5 m 넘게 벗어남; 물체 표면점이 참조에서 0.5 m 넘게 벗어남; IG 벡터 상대 오차 > 1; 참조에선 손이 닿아 있는데 시뮬 손이 20 스텝 넘게 연속으로 떨어짐 (p.4 "contact mismatch for 20 frames"; compute_humanoid_reset).
  • 밀린 직후 20–60 스텝 동안 추종 종료를 끔(유예), 서 있기 에피소드는 넘어짐만 종료 (p.4 "short grace period"; _compute_reward).
  • 에피소드: 300 스텝 (약 5.1 s), 참조의 무작위 프레임에서 시작, 초기 잡음 루트 위치 0.05 m·회전 0.04 rad·관절 0.15 rad·물체 위치 0.04 m·회전 0.08 rad (_DEFAULT_NOISE_STD).
  • 서 있기 에피소드: 참조 프레임을 고정. 논문 "occasional", 코드 1 % (주석은 10 %) (p.4; stand_still_ratio).
  • 리타게팅은 참조 상태 초기화를 안 쓰고 기본 서기 자세에서 첫 프레임을 따라가다 가중치를 서서히 올려 전체 추종으로 (p.4).
  • 증류 중 종료: 넘어짐만 (IG·접촉 종료 끔) (distill_obj_v2vae.py _compute_reset).

6-3. RL 미세조정 (증류 유지 PPO)

  • env 나누기: 앞 1/4 (1024 env) = 증류 env (encoder 포함, teacher 라벨, 위 손실), 뒤 3/4 (3072 env) = RL env (prior 단독 = 배포형 정책으로 굴림) (p.10; prior_mask[num_envs // 4:] = True).
  • 무엇을 학습: prior 쪽 + 0 초기화된 새 FiLM 층(스케일 0.1) + critic. decoder·encoder 동결 → 시작 순간 정책이 증류 결과와 똑같다 (_freeze_encoder_decoder_weights).
  • 워밍업: 논문 "정책경사 항을 처음 100 epoch 에 걸쳐 서서히 켬, critic 은 처음부터". 코드: actor 계수 = 0 (epoch 0–100) → 0 에서 1 로 선형 (100–200) (ultra_agent_distill_vae_rl.py 674 행).
  • 보수적 갱신: RL 손실 전체 × 0.2 ("작은 상수") (같은 파일 688 행).
  • 섭동: 물체 목표·루트 목표·초기 상태에 무작위 오프셋, 점구름 잡음(jitter·dropout·occlusion) 주입 (p.5).
  • advantage 정규화는 RL env 표본만으로 (_calc_advs).

10. 한계

  • 저자 명시: 상자형 물체만(정교한 손 없음), 동적 보행 제한, 지각 모델을 처음부터 학습 (p.7); 심한 가림·마커 가림·공격적 목표에 취약 (p.11).
  • 평가 규모가 작다: MuJoCo 설정당 20 회, 실기 과제당 2 회 (총 10·26 회). 벽시계 시간·GPU 수 없음.
  • 통합 비용: 통합 student 67.30 % 는 추종 전용 증류 85.03 % 보다 18 pt 낮다 — 모달을 묶을수록 손해.
  • 지각 격차가 실기에 남는다: 같은 정책이 MoCap 80–90 % 대 자기중심 50–60 %.
  • 시뮬 점구름이 이상적: 물체 PCA 상자 표면에서 바로 뽑아 실제 깊이 렌더·다중 반사·손 가림 기하는 없음(구형 가림·드롭으로만 흉내).
  • 하위·상위 분리 구조 아님: 동결 보행 제어기 위에 상위를 얹는 경우의 명령 인터페이스 문제는 다루지 않음.
  • 재현 시 논문 표와 코드 값이 여러 곳에서 다름 (9 절).

11. 우리에게 가져올 것

  1. student RL 미세조정 일정 (가장 직접적): dev10 v2 student (Isaac 69 %, MuJoCo 50 %) 같은 DAgger student 위에 env 1/4 은 DAgger 손실 유지, 3/4 는 배포형 student 로 PPO. critic 만 먼저 100 epoch (actor 계수 0) → 다음 100 epoch 에 actor 0 → 1; RL 손실 × 0.2; horizon 16, minibatch 8192, mini-epoch 4, 학습률 2e-4 → 5e-5. 보상은 teacher 과제 보상을 그대로 쓰되 ULTRA 처럼 "조밀 exp(−2·d) + 진척(±0.5 자르기) + 마감 시 한 번 주는 성공 보너스 10" 구조. ULTRA 에서 이득은 ID +14–19 %, OOD +80–200 % 라 우리 MuJoCo 격차(분포 이동) 쪽에 효과를 기대 (추론).
  2. 고정 σ + bounds loss 로 std 폭발·포화 막기: ULTRA 는 σ 를 학습하지 않고 log σ = −2.9 고정, entropy 0, |μ| > 1 에 10·(|μ| − 1)². dev10 v2 의 "env 안 자르기에 벌점 없음 → PPO std 폭발"과 on/off 포화 출력에 대한 직접 처방. 미세조정 단계엔 그대로, 탐색이 필요한 teacher 학습엔 σ 상한(clamp)만 가져오는 것을 권장 — ULTRA teacher 는 조밀 추종 보상이라 탐색 부담이 작다 (추론).
  3. 미세조정 때 새 층은 0 초기화: decoder 를 동결하고 0 초기화 FiLM(스케일 0.1)만 더해 첫 순간 정책을 바꾸지 않는다. 우리 student 미세조정·출력 확장(예: 골반 명령 추가) 때 같은 요령으로 시작 붕괴를 막을 것.
  4. 한 손 밀기 대책으로 "손 접촉 이탈 종료": ULTRA 는 참조상 닿아야 할 손이 20 스텝 넘게 떨어지면 종료. 우리는 참조 대신 단계 라벨로 — 조이기 단계 진입 뒤 한쪽 손바닥이 상자에서 20 스텝 (50 Hz 에서 0.4 s) 넘게 떨어지면 종료 (추론).
  5. 보조 복원 헤드: student 격차를 접촉 정보 탓으로 본다면, 깊이 + 고유감각에서 상자 상대 위치·자세, 양손 접촉, "들렸는가"를 예측하는 헤드를 계수 1.0 MSE 로 (ULTRA LA·LG 계수 1.0).
  6. 물체 DR (조이기 미끄럼 대비): ULTRA 실기 실패 1순위가 마찰 부족 미끄럼. 상자 마찰 0.2–1.2, CoM ±5 cm, 관성 × 0.5–2.0, 반발 0–0.3 을 출발점으로, 고무 공 손–상자 마찰 하한을 0.2 근처까지 내려 조임 여유를 학습시킬 것.
  7. 깊이 DR 출발값 (점구름 값을 픽셀로 옮겨): 점별 0.02 m, 거리 비례 1 %, 드롭 15 %, 이상점 5 % (0.5 m 이내), 구형 가림 10 %·반지름 0.1–0.4 m, 카메라 회전 0.05 rad·위치 0.02 m, 크기 × 0.95–1.05. G1 D435 피치 47.6° 가 K1 목 아래 47° 와 거의 같아 시야 기하가 비슷하다. 표현이 바뀌었으니 26×64 깊이 영상으로 옮긴 뒤 실기 D436 과 다시 대조할 것.
  8. DAgger 혼합 값: 에피소드 5 % 는 끝까지 teacher, 5 % 는 ‖μs − μt‖² > 0.5 일 때만 teacher 로 대체 — 회복 상태를 데이터에 계속 남기는 저렴한 방법.
  9. 평가 형식: MuJoCo sim2sim 에서 ID 와 OOD(학습 범위 밖 오프셋)를 나눠 미세조정 전후를 같은 세트로. 우리 OOD 세트 예: 앞 0.30 m 초과, 옆 ±0.15 m 초과, yaw ±40° 초과 상자.

가져오지 말 것

  • 통합 다중 모달 student (transformer + 64 차원 VAE 잠재 + 모달 마스크 + 4 개 보조 손실): ULTRA 자신의 표에서 통합 67.30 % < 추종 전용 85.03 %. 우리는 과제 하나·지각 하나 → CNN + MLP student 유지.
  • 모캡 리타게팅·참조 추종 teacher: 고무 공 손 옆면 조이기·받침대 높이 변화는 OMOMO 에 없고, 우리 teacher 는 참조 없는 과제 RL. 4052 차원 참조 잔차 관측도 해당 없음.
  • 29 관절 직접 출력·다리 동시 학습: 우리 하체는 dev12 동결. ULTRA 는 dev10 v2 의 "추종기가 못 따라가는 출력(허리)" 문제를 잠재 공간 출력으로 피했을 뿐 명시 명령 인터페이스의 해법은 아니다 → 우리 쪽은 dev12 학습 명령 범위(vx ±0.8, vy ±0.4, ωz ±1.0, 높이 0.335–0.77 m, pitch ±45°, roll ±10°)로 자르기 + 잘린 양 벌점.

  • 체크포인트 성공률 비단조: 논문에 선택 기준 없음 (해당 없음).
