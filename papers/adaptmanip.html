AdaptManip: Learning Adaptive Whole-Body Object Lifting and Delivery with Online Recurrent State Estimation

Morgan Byrd, Donghoon Baek, Kartik Garg, Hyunyoung Jung, Daesol Cho, Maks Sorokin, Robert Wright, Sehoon Ha · Georgia Tech, Georgia Tech Research Institute · 사전 공개 (arXiv v2 2026-09-30, RA-L 여부 미확인) · Unitree G1 29 DoF, 관절 없는 고무 손 · Isaac Lab (학습), MuJoCo (미학습 시뮬 평가)

로컬 PDF arXiv 2602.14363 morganbyrd03/adaptmanip (PDF·영상만) 유사도 5 논문만 (코드 없음)
G1 에서 PPO 보행 정책(명령 [v̄x, v̄y, ω̄, z̄] 을 따름)을 고정하고, 그 위 잔차 정책이 보행 명령 4 + 상체(허리·팔) 잔차 PD 목표 17 을 낸다. 상자 6D 자세는 AprilTag·고유감각·직전 행동을 섞는 LSTM(128) 추정기가 내고 정책과 함께 학습한다. 135 시행에서 전체 성공 Isaac Lab 0.85 · 미학습 MuJoCo 0.75 (Pure RL 0.62 / 0.37, Oracle 0.91 / 0.79), MuJoCo 재파지 6.32 회. 실기 G1 은 정성 시연 (p.4–6, 표 III).

1. 문제와 과제

  • 목표: 사람 시연·원격조종·모캡 없이 RL 만으로, 온보드 센서만 써서 "상자로 걸어가 → 들고 → 목표까지 나르기"를 자율로 (p.1–2, 표 I).
  • 세 단계 (p.3, 그림 2):
    1. 항법: 처음엔 상자가 카메라 밖. LiDAR-관성 오도메트리(FAST-LIO)로 상자 앞 목표 위치까지 이동.
    2. 잡기·들기: 상자에서 0.5 m 이내면 전환. 시각(AprilTag)을 켜 상자 자세를 정밀화. 고무 손이라 마찰로만 들어야 함.
    3. 운반: 몸·손에 상자가 자주 가려져 시각이 믿기 어려움.
  • 핵심 주장: 상자 상태 추정과 제어를 함께 학습하면, 미끄러짐·떨어뜨림 같은 실패에서 다시 잡는 회복 행동이 나온다 (p.1).

2. 시스템 구조

학습 3 단계 (그림 3, p.4)

① 무작위 속도·높이 명령 + 고유감각 → πwbc 학습 (Isaac Lab)→ πwbc 고정→ ② 잔차 πres 학습 + ③ LSTM 추정기 동시 학습(지도)

실행 시 (50 Hz, 물리 200 Hz)

AprilTag 자세(안 보이면 0) + 고유감각 + 실행한 행동→ LSTM 128 + MLP 머리 → 로봇 기준 상자 6D 자세 X̃box→ πres (MLP 512-256-128)→ ūloco = [v̄x, v̄y, ω̄, z̄]→ πwbc → at ∈ R29⊕ Δat (상체 17)→ PD: τ = kp(a + qdef − q) − kdq̇

점선 = 고정. 항법 단계는 LiDAR 오도메트리가 속도 명령을 만들고 πwbc 만 쓴다 (그림 2). 17 = G1 허리 3 + 팔 7×2 로 보이나 논문은 "주로 허리와 팔 관절"이라고만 씀 (p.4).

종료 · 커리큘럼 (p.5)

  • 종료: 20 s 경과, 기울기 60° 초과, 루트 높이 0.15 m 미만, 상자 높이 0.25 m 미만.
  • 상자 자세 커리큘럼(식 3): Xin = w·X̃box + (1 − w)·Xbox, w = min(t/T, 1), t = 학습 반복, T = 최대 반복. 초반엔 GT, 끝으로 갈수록 추정값을 정책에 넣는다.
  • 시각 흉내: 학습 중 렌더링을 하지 않고, 잡음과 무작위 가림을 씌운 GT 자세를 시각 측정 대신 넣는다. "실기로 잘 옮겨졌다" (p.5).

6. teacher → student / 증류

teacher → student 증류는 없다. 대신 한 정책 안에서 특권 상자 상태 → 추정 상자 상태로 옮겨 가는 방식을 쓴다. 우리 student 설계와 직접 비교할 만해서 정리한다.

요소AdaptManip우리 계획과의 차이
특권 정보 위치critic 만 GT 상자 자세·속도·접촉력을 봄. actor 는 처음부터 "추정 가능한 것"만 봄 (p.4)우리 teacher actor 는 특권 상태를 보고 student 가 깊이로 흉내 → 정보 격차가 생김(dev10 v2 student 69 %)
전환 방식정책 입력 = w·추정 + (1 − w)·GT, w 를 학습 반복에 따라 0 → 1 (식 3)DAgger 로 행동을 회귀
추정기 학습LSTM 128, GT 자세 지도 손실, 정책과 동시 (p.5)student 에 상자 자세 보조 머리를 붙일 수 있음
시각 입력학습 중 렌더링 없음. 잡음·가림을 씌운 GT 를 측정으로 사용. 실기 AprilTag 하나(윗면 가운데) (p.5–6)D436 깊이 26×64 를 학습 중 직접 렌더링

결과적으로 정책은 "잘 안 보이는 상자 자세"를 전제로 학습되고, 상자가 손에 붙은 뒤에는 고유감각과 행동 이력으로 추적한다. MuJoCo 에서 Oracle(테스트 때 GT) 0.79 와 AdaptManip 0.75 의 차이가 작다는 것이 근거다 (p.6 표 III).

8. 실기 · sim2real

  • 장비: Unitree G1 + RealSense D435i + Livox Mid-360 LiDAR. 모든 지각·제어 온보드, 외부 모캡 없음. 상자 윗면 가운데 AprilTag 하나, dt-apriltags 파이썬 바인딩 (p.6).
  • sim2sim 확인 뒤 추가 조정 없이 0 샷 배치 (p.6).
  • 결과는 정성 시연(그림 5, 6). 성공 횟수·시행 수는 논문에 없음 (p.7).
  • 관찰: 파지 형성 구간에서 양팔을 조심스럽게 맞춘 뒤 들고, 든 뒤 손 위치는 거의 고정. 끝 무렵 한 번 파지가 흔들리자 작은 팔 보정으로 회복. 걸을 때 상자가 시야를 벗어나면 시각 추정은 무너지지만 순환 추정은 계속 추적 (p.7, 그림 6).

11. 우리에게 가져올 것

  1. 가져올 것 — 행동 꼴에 대한 확신: 동결 보행 명령 + 상체 잔차라는 우리 구조가 G1 고무 손 상자 들기에서 Isaac 0.85·MuJoCo 0.75 로 작동했다. 우리는 하위가 상체를 내지 않으므로 "잔차"의 기준을 고정 기본 팔 자세로 두고, 상체 11 = 기본 자세 + 유계 델타(우리 v2 의 절대·포화 출력 대신)로 낸다.
  2. 가져올 것 — 좌우 대칭 손실: PPO 손실에 거울 관측·행동 일관성 항을 넣는다. K1 상체 11(허리 yaw 부호 반전, 팔 좌우 교환·roll/yaw 부호 반전)과 골반 명령(vy·ωz·roll 부호 반전)의 거울 표를 dev12 대칭 손실 표와 같이 쓴다. 한 손 쪽으로 몸을 돌리는 국소해를 줄이는 데 도움이 되지만, 대칭 손실만으로 한 손 밀기가 사라진다는 증거는 이 논문에 없다.
  3. 가져올 것 — 몸–상자 상대 속도 보상: e−‖vroot − vbox‖ 를 든 뒤 유지·운반 구간에 넣는다. 우리 "서서 유지"의 팔 흔들림(박스 높이 폭 15 cm) 억제에 직접 맞는다.
  4. 가져올 것(부호 고쳐서) — 손 대비 상자 수직 미끄럼 벌점: 손마다 max(0, vhand,z − vbox,z) 를 든 뒤에만 벌한다(상자가 손바닥보다 아래로 빠질 때). 논문 표기 그대로 옮기면 반대 방향을 벌한다.
  5. 가져올 것(상대값으로) — 상자 높이 종료: 논문은 상자 < 0.25 m 면 종료. 우리 상자는 바닥(중심 약 0.145 m)에서 시작하므로 절대 높이는 못 쓰고, "들기 판정 뒤 상자 바닥이 시작 높이 + 2 cm 아래로 내려오면 종료"처럼 들기 뒤 상대 높이로 바꾼다.
  6. 가져올 것 — 두 시뮬 격자 평가: 질량 × 크기 × 마찰 × 시드 = 135 처럼, 우리도 Isaac(Newton)과 MuJoCo 에서 같은 격자(예: 질량 0.5 / 1.25 / 2 kg × 받침 0 / 0.1 / 0.2 / 0.3 m × 상자 마찰 3 단계 × 시드 5)로 재고 떨어뜨림·재파지 횟수를 함께 기록한다. 학습 시뮬에서 좋은 판(FK 0.88)이 미학습 시뮬에서 무너지는 것을 이 방식으로 잡았다.
  7. 가져올 것 — student 에 상자 자세 보조 머리: 깊이 student 에 순환층 + 상자 상대 자세(위치 3 + 회전) 지도 손실을 붙인다. 들고 서면 상자가 D436 시야의 70–92 % 를 가리므로(우리 측정), 잡은 뒤에는 고유감각·행동 이력으로 상자를 추적해야 한다는 이 논문의 결과가 그대로 적용된다.
  8. 가져올 것 — teacher actor 에서 접촉력 빼기: 접촉력·상자 속도를 critic 전용으로 둔 것이 sim2sim 에서 Oracle 과 4 %p 차이였다. dev10 v2 student 격차의 원인으로 지목된 접촉 정보를 teacher actor 에서 빼고 critic 으로만 옮긴다. 옮기는 방법으로 w = min(t/T, 1) 혼합 같은 점진 전환을 teacher 학습 후반에 시험할 만하다.
  9. 가져오지 말 것 — 접촉력 합 clamp(Σ‖f‖, 0, 1) 접촉 보상: 힘 합이 단위 1 에서 포화되어 한 손만 닿아도 최대값이다. 우리 한 손 밀기 문제에는 두 손 중 약한 쪽 힘(min)으로 주는 보상이 맞다.
  10. 가져오지 말 것 — 지각 파이프라인과 DR 값 그대로: AprilTag·LiDAR 는 우리 경로가 아니다. 상자 질량 −0.88–1.5 kg 가산은 기본 질량이 없어 옮길 수 없고, 우리는 절대 0.5–2 kg 을 쓴다. kp·kd ×0.8–1.2, 지면 마찰 0.3–1.5, 상자 마찰·반발 범위는 참고값으로만.
