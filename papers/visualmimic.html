사람 동작으로 teacher→student 증류한 과제 무관 키포인트 추종기(명령 18 차원, 50 Hz)를 동결하고, 그 위에서 과제마다 특권 PPO teacher → 깊이 80×45 DAgger student 로 키포인트 명령 생성기를 학습한다. 상위 출력은 하위 정규화기 통계의 μ±1.64σ 로 자르고 하위는 명령 ×U(0.5, 1.5) 잡음으로 학습한다. 자르기를 빼면 Kick Ball 189 → 12 m, 잡음을 빼면 Push Box 151 → 2 m. G1 실기 상자 들기(0.5 kg, 1 m 높이)·밀기(3.8 kg)·공 드리블·상자 차기 전이(정성).

1. 문제와 과제

  • 목표: 외부 모캡 없이 로봇 자기 카메라(egocentric)만으로 물체와 전신 상호작용(밀기·차기·들기)을 하는 sim-to-real RL (p.1–2).
  • 문제의식: 시각 RL 은 행동·탐색 공간이 커서 앉기·계단 수준에 머물고, 모방 학습은 시연 데이터가 부족하다 (p.2).
  • 해법: 계층 분할. 하위 = 사람답게 움직이는 과제 무관 추종기, 상위 = 과제별 "단순화된 추종 명령" 생성기 (p.2–3).
  • 쌍을 이룬 사람-물체 동작 데이터 없이, 과제 보상 몇 개만으로 학습한다 (p.2, p.5).

3. 관측과 행동

3-1. 키포인트 명령 (p.5, 식 1–3)

  • ckpt = [Δpt, Δx1t, …, Δx5t] → 3 + 5×3 = 18 차원.
  • 루트 위치 오차 Δpt = pdest − pcurt.
  • 키포인트 오차 Δxit = (xi,dest − pdest) − (xi,curt − pcurt), i = 머리·두 손·두 발.
  • 추종기의 몸 위치·루트 속도 추종은 세계 좌표. 지역 좌표판은 크게 떨어짐 (표 III "Local-Frame Tracker").
  • 그림 2 에서 "6 점" = 루트 + 5 키포인트. 상체 키포인트만 쓴 변형은 발을 못 써 Balance Ball 실패 (p.8).

4. 보상 · 종료 · 커리큘럼

4-1. 하위 추종기 보상

  • rmotion = rtrack + rpenalty: 정확한 동작 추종 + 떨림·발 미끄럼 벌점. 구조는 TWIST [5] 를 따름, 세계 좌표 몸 위치·루트 속도 추종 (p.3, p.5).
  • 항별 식·가중치: 논문에 없음 (TWIST 참조).

6. teacher → student / 증류

6-1. 하위: 동작 추종기 → 키포인트 추종기

  • teacher 는 배포하지 않으므로 미래 2 s 참조와 발 접촉력 같은 특권 정보를 넣어 정확·부드럽게 추종 (p.3).
  • student 는 고유감각 + "그 시각 참조 프레임에서 계산한" 키포인트 명령만 보고 DAgger 로 teacher 를 따라함 (p.3).
  • 이유: 키포인트만으로 바로 RL 하면 사람답지 않은 동작 (그림 6, 상자 차기). 1단 RL 추종기는 생성기 학습 때 "매우 부자연스러운" 행동 (p.9).
  • student 학습 때 명령에 ×U(0.5, 1.5) 잡음 → 상위의 거친 명령에 견디고 HMS 자체를 넓힘 (p.6).
  • 주의: p.5 본문은 이 절에서 "πteagenerator 를 πstugenerator 로 증류"라고 적었으나 문맥상 tracker 의 오기.

6-2. 상위: 상태 teacher → 깊이 student

  • teacher: 물체 상태 + 고유감각 → PPO. 시각 RL 을 바로 하면 물체 위치·접촉력이 부분 관측이고 IsaacGym 렌더가 느려 비효율 (p.5).
  • student: RGB 는 sim-to-real 격차가 커서 깊이만 시각으로 사용. CNN 출력 + 고유감각 → MLP, DAgger (p.6).
  • DAgger 세부(β 일정, 버퍼, 손실, 반복 수): 논문에 없음.
  • student RL 미세조정: 없음. 증류 손실이 그대로 격차로 남는다 (7 절 표 II).
  • 같은 스텝 수의 시각 RL 직접 학습: Push Box 25 m (우리 방식 37 m), Kick Box·Kick Ball 0 (표 III).

7-3. 행동 관찰

  • Push Box 에서 조건에 따라 전략이 바뀜: 바닥 μ 0.5 → 숙여 두 손으로, μ 1.5 → 어깨로 기대어, 상자가 낮으면 한 손 밀기 + 다른 팔은 보폭 따라 흔들기 (p.8, 그림 7).
  • 상체 키포인트만 쓴 변형: 발을 공 위에 못 올리고 계속 차 버림 (p.8).
  • 학습 곡선의 분산(그늘)이 크다 — 체크포인트·시드마다 성능이 들쭉날쭉 (그림 9).

8. 실기 · sim2real

  • 로봇: Unitree G1 + 내장 RealSense D435i. Lift Box, Kick Ball, Kick Box, Push Box 4 과제가 "모두 전이 성공" (p.7).
  • 실기 성공률·시행 수: 논문에 없음 (사진·영상 정성 보고만).
  • 실외(조명 변화·고르지 않은 땅·주변 방해물)에서도 동작 (p.7, 그림 3).
  • 실기 깊이는 잡음이 커서 공간·시간 필터 적용. 필터 후에도 시뮬과 격차가 커서 학습 때 강한 마스크 (p.6, 그림 8).
  • 실패 모드: 마스크 없이 학습하면 배포 때 "불안정한 행동". G1 목이 단단히 고정되지 않아 카메라 각도가 흔들림 → 방향 ±5° 무작위 (p.6).
  • 안전: 0/1 명령으로 정지/수행 전환. 항상 정지 상태로 시작, 프로그램을 그냥 끄면 넘어질 수 있어서 도입 (p.6). sim2sim 은 50 스텝(1 s) 정지 뒤 1 로 바꿈 (sim2sim.py 197, 238–243 행).
  • 지연 모델·처리: 논문에 없음. sim2sim 은 깊이를 5 ms 마다 렌더하고 최신 1 장을 그대로 사용 (지연 없음).

9-2. 체크포인트 안의 실제 배포 경로

각 .pt 는 HardwareRefNN 하나: high_level_actor (깊이 student) + low_level_policy (키포인트 추종기) + 정규화기 둘. forward 순서:

  1. obs[:, 0:4370] → 상위 정규화기 → 상위 actor → 18 차원 출력.
  2. actions_clipped = clamp(출력, −1.64, 1.64).
  3. [clipped, 하위 관측 994] 를 이어 11 프레임 × 92 로 펼친 뒤 하위 정규화기로 정규화.
  4. 11 프레임의 명령 칸 0:18 을 정규화하지 않은 값으로 다시 덮어씀 → 상위 출력은 처음부터 하위의 "정규화된 명령" 단위다. 따라서 ±1.64 자르기 = 물리 단위 μ±1.64σ (3-4 절 표).
  5. 하위 actor → 23 관절. 출력 = [상위 18, 하위 23].
  • sim2sim 은 상위 출력(잘린 값)을 하위 관측 이력의 명령 칸과 상위 관측의 "직전 상위 행동"에 그대로 넣는다 (sim2sim.py 292–305 행).
  • 하위 actor·이력 인코더·하위 정규화기 텐서의 md5 가 네 과제에서 같음 → 과제 무관 공유 추종기 확인. 상위 actor·상위 정규화기는 과제마다 다름.
  • 체크포인트 이름: 0901_lift_box_tune_v2_7k_stu-9000, 0825_push_box_two_hand_robust_sample_longer_tune_750_stu-1000, 0826_kick_ball_command_stu-2000, 0822_kick_box_v5_stu_v2-10000 → 과제마다 다른 반복에서 고른 student.
  • 자르기는 배포 때 결정적 평균 출력에 적용된다. 학습 중 샘플 행동을 어디서 잘랐는지, 잘린 양 벌점이 있었는지는 학습 코드가 없어 확인 불가.

10. 한계

  • 저자 언급: 변형 물체·사람 협업 미검증, 긴 과제·다양한 실환경엔 DR·적응 제어가 더 필요 (p.9).
  • 실기 성공률·시행 수 없음. 비교·재현이 어렵다.
  • 보상 가중치, PPO·DAgger 설정, env 수, 학습 시간, 종료 조건, 커리큘럼이 모두 논문에 없고 학습 코드도 미공개.
  • Lift Box 는 0.5 kg 가벼운 큰 상자 하나, 윗면 0.51 m. teacher 떨어뜨림률 34 %로 들기 자체가 확실히 풀린 것은 아니다. 낮은 상자·받침대·무거운 상자·들고 걷기는 다루지 않음.
  • 순수 DAgger 라 student 격차가 크다 (Push Box 152 → 37 m).
  • μ±1.64σ 는 각 차원을 독립 가우시안으로 본 상자 자르기다. 차원 사이 결합(예: 손 높이와 루트 높이)은 못 담는다.
  • 키포인트 칸 순서·정의가 코드로 확인되지 않음 (3-4 절 칸 6–8).

11. 우리에게 가져올 것

  1. 상위 행동을 "하위가 학습 때 본 명령 분포의 정규화 단위"로 정의하고 ±1.64 로 자른다. 골반 명령 6 칸은 dev12 학습 명령 분포(정규화기가 있으면 그 μ, σ)에서 z 값으로 내고 clamp ±1.64. 균등 분포라면 μ±1.64σ = 범위의 94.7 %: vx ±0.757, vy ±0.379, ωz ±0.947, 서기 높이 0.347–0.758 m, pitch ±42.6°, roll ±9.5° (계산값). 상체 11 목표도 dev12 가 학습 때 본 목표 분포의 μ, σ 로 같은 처리 → v2 의 "추종기가 못 따르는 허리 출력" 문제에 대응.
  2. 자르기에 잘린 양 벌점을 꼭 붙인다. VisualMimic 은 자르기만 쓰고 벌점은 언급이 없다. 우리 v2 는 환경 안 자르기 + 벌점 없음으로 PPO std 가 발산했다 → 원 행동의 경계 초과분 L2 벌점 (VIRAL 식) + std 상한. 학습 중 경계에 붙은 비율을 로그로 남겨 켜짐/꺼짐 포화를 감시.
  3. dev12 재학습 때 명령 잡음. 명령 차원마다 독립 ×U(0.5, 1.5). 골반 명령은 vx·vy·ωz 와 (높이 − 기본), pitch 의 편차에 곱한다. 이 잡음 하나가 Push Box 2 m ↔ 151 m 를 갈랐다 (표 III).
  4. 두 손 접근은 조화 평균으로. 2e₁e₂/(e₁+e₂) 는 먼 손이 지배하므로 v2 의 "한 손 밀기" 국소 최적을 직접 깎는다. 단 척도는 다시 정한다: e−0.1d 를 m 로 쓰면 0–0.3 m 에서 1.0–0.97 로 평평 → 우리 손–옆면 거리엔 e−d/0.1 m 급 (추론). 그림 7 처럼 낮은 물체에선 한 손 전략이 자연히 나오므로 조화 평균 없이는 재발할 것.
  5. 조임 힘은 한쪽 문턱 보상. e−0.1[Fdes−F]+ 를 손마다 걸고 Fdes ≥ m g / (2 μ) 에 여유 (2 kg, μ 0.8 이면 손당 약 12 N, 추론). 팔 kp 22.3 이라 "닿기만" 하면 수 N 뿐이므로 명시적 조임 보상이 필요하다.
  6. "새 최고 기록" 진척 보상. tanh(10[zbox − maxt′<t zbox]+) 꼴로 상자 높이를 보상하면 들썩임·흔들기로 보상을 타먹지 못한다. 옆 이탈도 Rdrift 꼴로.
  7. 0/1 정지 명령을 상위 관측에 넣고 50 %로 섞어 학습. 정지 = 서기 유지 보상. K1 배포 때 항상 정지로 시작 → 손으로 과제 시작, 비상 시 정지로 복귀.
  8. 깊이 DR 출발값. 고정 마스크 20 %, 최대 6 개 사각 마스크 각 10 %, 흰·검정·회색 U(0, 1), 한 개 최대 화면 25 % (우리 26×64 crop 이면 약 17×24 px). 카메라 방향 무작위는 ±5° 가 G1 목 흔들림 기준이므로 K1 은 실측 장착 오차(목 0°/47° 수동 고정) 이상으로. 실기 깊이엔 공간·시간 필터를 같은 방식으로 학습 쪽 마스크와 짝지을 것.
  9. 체크포인트는 고른다. 저자들도 과제마다 1000–10000 반복 중 다른 student 를 골랐고 학습 곡선 분산이 크다. 우리 "체크포인트마다 성공률 들쭉날쭉"은 정상 현상으로 보고 이웃 저장본과 같은 지표로 비교해 고른다.

가져오지 말 것

  • 키포인트 인터페이스로 갈아타기: 하위를 키포인트 추종기로 재학습해야 하고 사람 동작 teacher 가 필요하다. DoF 인터페이스 실패(Push Box 152 → 10)는 다리까지 23 관절을 상위가 정한 경우라, 다리를 dev12 가 맡는 우리 분할을 그대로 반박하지는 않는다. 다만 팔 11 관절 직접 탐색이 약하다는 경고로 받아 "단계별 명목 팔 자세 + 작은 잔차"와 위 자르기로 탐색 공간을 줄인다.
  • 세계 좌표 추종: 논문에선 지역 좌표보다 좋았지만 K1 엔 베이스 속도·위치 추정기가 없다. dev12 의 골반 속도 명령 인터페이스를 유지.
  • 순수 DAgger 로 격차가 닫힌다는 기대: 여기도 접촉 과제 격차가 크다(Push Box 152 → 37, Kick Box 앞 78 → 30). 우리 student 격차(90 → 69 %)를 접촉 정보 탓으로 본 해석과 맞으므로 DAgger 뒤 student RL(PRISM λ 혼합 등)을 계획에 둔다.
  • 깊이 1 장 설계: 그들은 최신 1 장 + 고유감각 이력으로 충분했지만 증거는 밀기·차기 위주다. 우리 6 프레임은 조임·들림 판단 때문에 유지 (논문은 근거 없음).
  • Lift Box 를 "풀린 문제"의 기준으로 삼기: 0.5 kg·윗면 0.51 m·teacher 떨어뜨림 34 %. 바닥 29 cm 높이 상자 도달 한계(v2)에 대해 이 논문은 아무 근거도 주지 않는다.
