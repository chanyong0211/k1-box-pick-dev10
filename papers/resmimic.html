ResMimic: From General Motion Tracking to Humanoid Whole-body Loco-Manipulation via Residual Learning

로컬 PDF 로컬 코드 arXiv 2510.05070 amazon-far/ResMimic 프로젝트 페이지 유사도 2–5 Apache-2.0 가중치
AMASS·OMOMO 약 42 시간으로 학습한 GMT 를 고정하고, 물체 상태를 보는 잔차 정책이 a = aGMT + Δa(29 차원)를 낸다. 가상 물체 PD 힘 커리큘럼·점구름 물체 보상·접촉 보상을 더해 MuJoCo 4 과제 평균 성공 92.5 %(GMT 단독 10 %, 처음부터 0 %, GMT 미세조정 7.5 %), 수렴 1,300 iter (p.5 표 I).

1. 문제와 과제

  • 문제 (p.1–2): GMT 는 사람 동작을 잘 따라 하지만 물체를 모르고 정밀하지 않다. 리타게팅한 사람–물체 데이터는 몸 크기 차이 때문에 손이 물체를 뚫거나 허공에 떠 있다(그림 2). 기존 로코매니퓰레이션은 단계별 제어기·과제별 데이터 파이프라인에 의존.
  • 관찰: 균형·발 딛기·뻗기 같은 전신 동작은 과제 간에 공유되고, 물체와의 세밀한 상호작용만 과제별로 고치면 된다 → 사전학습 + 잔차 사후학습.
  • 과제 4 개 (p.6): Kneel, Carry(등에 업기), Squat(팔과 몸통으로 들기 — 전신 접촉), Chair(무겁고 불규칙한 의자 들기). 참조는 OptiTrack 으로 사람·물체를 함께 녹화.

2. 시스템 구조

1 단계: GMT (과제 무관, 고정 대상)

AMASS + OMOMO 15,000+ 클립(약 42 h), 계단 등 제외→ GMR 리타게팅 → G1 참조→ PPO 로 πGMT 학습 (TWIST 보상·DR)→ πGMT 고정 (base_policy.pt)

2 단계: 잔차 (과제별, 학습)

고유감각 + 사람 참조→ πGMT → aGMT⊕ πRes(고유감각, 물체 상태, 사람 참조, 물체 참조) → Δa→ a = aGMT + Δa → 관절 목표 (×0.5) 50 Hz→ PD 500 Hz
가상 물체 PD 힘 F = kp(p̂ − p) − kdv, 토크 동일 꼴→ kp·kd 를 점차 줄여 0 으로 (학습 초기만 받쳐 줌)

3 단계: 실기

고유감각 (+ 선택: MoCap 물체 상태)→ πGMT + πRes→ G1

주기: 코드 sim dt 0.002 s × decimation 10 = 정책 50 Hz, 물리 500 Hz. GMT 는 torch.jit.load 로 불러 no_grad + detach() — 그래디언트가 흐르지 않는 완전 고정.

커리큘럼 · 초기화

  • 가상 물체 제어기 커리큘럼 (p.4): 매 스텝 물체에 Ft = kp(p̂o − po) − kdvo, Tt = kp(θ̂o ⊖ θo) − kdωo 를 가하고 이득을 점차 줄임. 시작 이득·감쇠 일정은 논문에 없음.
  • 이유: 리타게팅 관통 때문에 참조를 그대로 따라 하면 물체를 쳐서 넘어뜨리고 → 물체 보상이 낮고 조기 종료가 잦아 → 로봇이 물체에서 물러나는 국소해에 빠짐(그림 7). 무거운 물체의 초기 불안정도 막음.
  • 잔차 0 근처 초기화: 마지막 층을 작은 gain 의 Xavier 균일 초기화 (p.4). 코드: final_layer_gain = 0.01, init_noise_std = 0.1(GMT 학습은 1.0).
  • RSI: 참조의 임의 시점 시작(rand_reset)은 HOI 설정에서 꺼짐(rand_reset = False). 물체 초기 위치 ±0.02 m, yaw ±5° (코드).

6. teacher → student / 증류

잔차 단계에는 증류가 없다(train.sh 의 --teacher_exptid None → KL 항 꺼짐, 순수 PPO). 논문은 GMT 를 "특권 정보 없이 단일 단계 RL"로 학습했다고 적는다 (p.3).

  • 코드에는 TWIST2 에서 온 teacher → student 경로가 남아 있다: 특권 teacher(G1MimicPrivCfg, 미래 20 시점 참조 + 특권 정보) → student GMT(DaggerPPO = PPO + teacher 분포와의 KL, 계수 0.2 → 0.1 을 60,000 스텝에 걸쳐 감소). 공개 base_policy.pt(내부 이름 0815_new_kpkd-15000-jit, 15,000 iter 로 보임)가 어느 경로로 학습됐는지는 확인 불가.
  • LessMimic 은 이 ResMimic 을 teacher(πmimic)로 써서 참조 없는 정책을 BC 로 증류했다(LessMimic 부록 A).

절제 (p.7–8, 정성)

  • 가상 물체 제어기 없음(그림 7): 손–물체 관통이 있는 참조에서 물체를 쳐서 넘어뜨리고, 낮은 물체 보상·잦은 조기 종료로 "물러서기" 국소해. 있으면 초기에 물체가 안정돼 정밀한 조작으로 수렴.
  • 접촉 보상 없음(그림 8): 상자를 손목·손만으로 드는 해로 수렴 → IsaacGym 에선 되지만 MuJoCo·실기에서 실패. 접촉 보상이 있으면 사람처럼 몸통 + 팔 접촉을 써 전이가 좋아짐(몸통 접촉력 그래프로 확인).

  • Unitree G1(29 DoF, 1.3 m). blind(물체 상태 없이, 그림 1 전부)와 non-blind(MoCap 물체 상태, 그림 4) 둘 다 가능 (p.7).
  • 그림 1: 한 무릎 꿇고 상자 들기, 상자 등에 업기, 의자에 앉았다 일어서기, 4.5 kg 상자를 전신 접촉으로 운반(G1 손목 하중 한계 약 2.5 kg), 4.5 kg·5.5 kg 의자 들기.
  • 그림 4 (non-blind): 무작위 물체 초기 자세에서 상자 들기 11 회 연속, 무릎 꿇고 들기 연속, 외부 밀기에 반응.
  • 그림 6: 실기에서 GMT 단독은 겉보기 동작만 따라 하고 물체를 놓침(불완전한 시연 데이터에서 더 심함), 처음부터 학습·미세조정은 sim2real 차이로 완전히 실패.
  • 성공률 표는 없다. 실패 사례 설명도 없다.

10. 한계

  • 과제마다 MoCap 사람–물체 참조 1 개와 잔차 정책 1 개. 참조 밖 물체 배치·크기 일반화는 시험하지 않음(초기 물체 ±2 cm).
  • 실기 non-blind 는 MoCap 물체 상태 필요. 시각 없음.
  • 성공 임계 σo, 보상 계수, 가상 힘 감쇠 일정 등 핵심 값이 논문에 없고, 공개 코드에는 그 장치 자체가 없다.
  • 평가 과제당 성공률이 10 % 단위(시행 10 회로 보임), 실기는 정성 시연뿐.

11. 우리에게 가져올 것

  1. 근거 — dev12 는 고정한다: GMT 미세조정 7.5 %(MuJoCo 에서 무너짐) vs 고정 + 잔차 92.5 %, 수렴도 2,400 대 1,300 iter. 상위 학습 중 하위를 같이 고치지 않는다. 고쳐야 한다면 과제 보상이 아니라 원래 추종 보상으로, 별도 단계에서.
  2. 구조 확인 — 상체는 추종기 뒤에 직접: ResMimic 이 정밀 조작을 낸 것은 잔차가 추종기 출력(관절 목표)에 더해졌기 때문이다. dev10 v2 는 SONIC 의 입력에 오프셋을 넣어 허리 등 추종기가 못 따라가는 출력이 생겼다. 이번 설계(상체 11 = PD 직행, 다리만 골반 명령)는 팔에 대해 ResMimic 과 같은 위치이므로 유지하고, 다리 쪽은 명령 범위를 dev12 가 실제 도달하는 영역으로 묶는다.
  3. 가져올 것 — 출력 0 근처 초기화 + 작은 초기 std: 마지막 층 Xavier gain 0.01, 초기 std 0.1(코드). 우리 상위 출력(상체 목표 델타·골반 명령 델타)도 처음엔 "서서 기본 자세 유지"와 같게 시작해 dev12 가 학습 분포 안의 명령만 받게 한다. dev10 v2 의 켜짐/꺼짐 포화·std 발산은 초기 std 1.0 + 환경 안 자르기와 맞물렸으므로, 초기 std 를 0.1–0.3 으로 낮추고 std 상한·감소 일정(코드: 4,000 갱신 뒤 1.0 → 0.4 배)을 함께 둔다.
  4. 가져올 것 — 가상 상자 보조 힘 커리큘럼: 학습 초기에 상자를 목표(들어 올린 높이) 쪽으로 PD 힘·토크로 받쳐 주고 이득을 0 까지 줄인다. 우리 쪽 구체안: 상자에 위쪽 보조 힘 α·m·g + 목표 높이로의 PD(α 1 → 0), 감쇠는 iteration 고정 일정 대신 성공률 기준으로 내리고, 평가는 항상 α = 0 으로. 논문이 이득 값을 주지 않았고 공개 코드에도 없으니 값은 우리가 정해 실험해야 한다. 기대 효과: 한 손 밀기·물러서기 국소해 전에 "들면 보상" 경험을 먼저 준다.
  5. 가져올 것 — 점구름 상자 보상: 상자 표면 N 점의 현재 vs 목표(들어 올린 자세) 평균 거리 d 로 exp(−10·d)(코드 계수), 가중 2.0. 위치와 기울기를 한 항으로 다뤄 상자 기울어짐(옆면 조이기에서 잘 생김)도 같이 벌한다.
  6. 가져올 것 — 종료 두 가지: 상자 점 평균 오차 > 0.3 m 이면 종료(코드), 필요한 접촉이 10 프레임(0.2 s) 넘게 끊기면 종료(논문). 우리는 "두 손 접촉이 성립한 뒤"부터 접촉 상실 종료를 켠다.
  7. 가져올 것 — 필요한 링크에만 접촉 보상: 접촉이 필요한 링크(우리: 양 손바닥)에만 Σ ĉ·exp(−λ/f) 꼴로 힘에 비례한 보상. ResMimic 은 접촉 보상이 없으면 IsaacGym 에서만 되는 "손목만으로 들기"로 수렴해 전이 실패했다 — 시뮬에서만 통하는 접촉 방식을 막는 장치. 우리 경우 두 손 각각의 힘을 따로 보상하고 약한 쪽 기준(min)으로 묶는다.
  8. 평가 방식: 모든 비교를 MuJoCo sim2sim 으로 했다(IsaacGym 성공이 MuJoCo 실패로 바뀌는 경우를 직접 보임). 우리도 Isaac 성공률 대신 MuJoCo 성공률로 체크포인트를 고른다(dev10 v2 student 가 Isaac 69 % → MuJoCo 50 % 였던 차이를 같은 방식으로 추적).
  9. 가져오지 말 것 — 다리에 잔차: ResMimic 은 29 관절 전부에 잔차를 더한다. 우리는 다리를 dev12 명령으로만 움직이고 다리 관절 잔차는 넣지 않는다(넣으면 dev12 학습 분포 밖 상태가 되고 하위 고정의 이점이 사라짐).
  10. 가져오지 말 것 — 과제별 MoCap 참조 추종: 사람–물체 참조 1 개를 따라 하는 방식은 우리 상자 배치 무작위(앞 0.04–0.30 m, 옆 ±0.15 m, yaw ±40°, 받침 0–0.3 m)에 맞지 않고 K1 용 HOI 참조도 없다. 무릎 꿇기(Kneel 90 %)도 우리 하위 명령 공간 밖.
  11. 라이선스: Apache-2.0 — 잔차 합산·초기화·점구름 보상 코드는 옮겨 쓸 수 있다(legged_gym·rsl_rl 부분은 각 원 라이선스).
