1. 문제와 과제

다지 손 휴머노이드의 시각 기반 조작을 sim2real RL 로 풀 때 네 난점을 짚고 각각 처방한다 (p.2).

난점처방
A값싸고 잡음 많은 모터의 sim2real자동 실-시뮬 맞춤(autotune), 실기 데이터 4 분 미만
B양손 협응 보상 설계"접촉 목표 + 물체 목표", 접촉 표식(contact sticker)
C탐색사람이 시뮬에서 "놀아 본" 손 자세로 초기 상태, 물체별 전문가 → 증류(분할 정복)
D물체 지각성긴 3D 위치 + 밀집 분할 깊이를 함께, 모달리티별 무작위화

과제 (p.6, §4.2)

  • Grasp-and-reach: 한 손으로 탁상 물체를 집어 목표 위치로. 시작 때 스크립트가 물체에 가까운 손을 고름. 물체 모양·질량·부피·마찰·색·무늬 다양.
  • Box lift: 한 손으로 못 잡을 만큼 큰 상자를 두 손으로 들기. 상자 크기·색·질량·초기 자세(위치, yaw) 무작위. 구체 크기·질량 값은 논문에 없음.
  • Bimanual handover: 한 손으로 집어 반대 손에 건넴(반대 손은 물체에 직접 닿지 못함).

2. 시스템 구조

학습 파이프라인

실기 보정 궤적 (4 분 미만)→ autotune: 시뮬 파라미터 묶음 K 개 병렬 재생 → 추종 MSE 최소 선택→ 물체(군)별 전문가 PPO
초기 상태 = 사람 놀이 손 자세→ 성공 궤적만 저장 (100 env × 5,000 스텝)→ generalist diffusion policy (BC)

배포 (실기)

3 인칭 D435 (삼각대)→ SAM2: 첫 프레임 마스크 → 추적 → 마스크 중심 + 깊이 = 3D 물체 질량 중심, 5 Hz
머리 D435 깊이 → 물체 분할 깊이 → ResNet-18 (GroupNorm)+ 관절 + 3D 위치 → MLP (512, 512, 512) ELU → 64→ diffusion (100 단계) → 팔 7 × 2 + 손 6 × 2 관절 목표→ 관절 PD

학습이 끝난 전문가·autotune 값은 다음 단계에서 고정. 하위 보행 제어기는 없다.

(p.14, §6.3; p.15, §6.4)

  • actor 에 접촉력·질량은 처음부터 없다. 질량은 critic 의 "무작위화 배율"로만 들어가고, 접촉력은 어느 쪽에도 없음.
  • 깊이 해상도, 프레임 쌓기, 행동 범위·정규화 세부는 논문에 없음.
  • 비구동 관절은 qu = k · qa + b 선형 결합으로 근사하고 k, b 도 autotune 대상 (p.14, §6.1).

4. 보상 · 종료 · 커리큘럼

보상 = 접촉 목표 + 물체 목표 (p.4, §3.2; p.14, §6.2)

잡기·들기:   r(s_h, s_o) = r_contact(s_h, s_o) + r_goal(s_o)                                   (부록 식 1)

r_contact = Σ_i [ 1 / (1 + α · d(X^L, F^L_i))  +  1 / (1 + β · d(X^R, F^R_i)) ]
  X^L ∈ R^(n×3), X^R ∈ R^(m×3) : 왼·오른손용 접촉 표식 위치 (물체 표면 점)
  F^L, F^R ∈ R^(4×3)           : 왼·오른손 손가락 끝 4 개 위치
  d(A, x) = min_i ‖A_i − x‖₂    : 가장 가까운 표식까지 거리
  α, β : 척도 하이퍼파라미터 (값 논문에 없음)

r_goal : 물체 상태(예: xyz 위치)의 목표 상태 편차에 대한 벌점 (식·가중치 논문에 없음)

건네기:     r = (1 − a) · (r_contact(s_hA, s_oA) + r_goal(s_oA)) + a · (r_contact(s_hB, s_oB) + r_goal(s_oB)),  a ∈ {0, 1}
           단계를 마칠 때마다 보너스, 뒤 단계일수록 큼 (값 논문에 없음)                      (부록 식 2)
  • 접촉 표식: 시뮬 물체 표면에 "원하는 접촉 위치" 점들을 붙이는 것. 상자는 상자 치수에서 옆면·모서리를 따라 절차적으로 생성 (p.7, §4.4).
  • 표식 위치가 행동을 바꾼다 (p.7, 그림 5): ① 좌·우 옆면 중심 → 두 손이 옆면을 양쪽에서 끼워 듦, ② 위·아래면 중심 → 위아래로 잡음, ③ 아래 모서리 → 밑을 받쳐 듦. 같은 과제에서 표식만 바꿔 접촉 양상을 고를 수 있다는 정성 결과.
  • r_contact 는 손별 항의 합이다 — 한 손만 표식에 가도 보상의 절반 가까이를 받는 꼴. 한 손 밀기 같은 국소해를 어떻게 막는지는 논문에 없음.

종료 · 커리큘럼

  • 종료 조건, 에피소드 길이: 논문에 없음.
  • 사람 놀이 초기화 (p.5, §3.3): 시뮬 원격조종으로 과제를 염두에 두고 대충 "놀아" 기록한 상태(물체 자세 + 로봇 관절)를 에피소드 초기 상태로 무작위 추출. 시연 궤적이 아니라 상태만, 과제당 30 초 미만.
  • 그 밖의 난이도 커리큘럼은 논문에 없음.

5. 학습 설정 (알고리즘 · 망 · 무작위화)

전문가 RL (p.14, §6.3)

  • PPO + 비대칭 actor-critic. actor · critic 모두 MLP (512, 512, 512).
  • PPO 하이퍼파라미터, env 수, 반복 수, 학습 시간: 논문에 없음. 그림 4 학습 곡선 가로축(env 스텝) 눈금은 읽을 수 없을 만큼 작다.
  • 물체는 원기둥·정육면체·구 같은 기본 도형 + 물리 파라미터 무작위. 복잡한 형상보다 빨리 수렴하고 처음 보는 실물로 일반화 (p.6–7, 그림 4 왼쪽).

autotune (p.4, 알고리즘 1)

  1. 조정할 파라미터 집합 E 와 초기 로봇 모델 M 으로 파라미터 공간 P 를 만든다. 시뮬 쪽(관절 강성·감쇠·armature·effort, 마찰 등)과 URDF 쪽(링크 원점·질량·관성, 관절 원점·한계)을 함께.
  2. P 에서 K 개(모집단)를 뽑아 시뮬 env K 개를 만든다.
  3. 관절 목표 시퀀스 N 개를 만들어 실기에서 실행 → 실기 추종 오차 기록.
  4. 같은 시퀀스를 시뮬 K 개에서 실행 → 실기 추종 오차와의 MSE 가 가장 작은 파라미터를 고름.

실기 데이터 4 분 미만(10 Hz 로 2,000 스텝) (p.4). 반복 최적화 없이 한 번 뽑아 고르는 무작위 탐색이다.

6. teacher → student / 증류

  • 방식: 전문가마다 100 env × 5,000 스텝을 평가하며, 에피소드 리셋 때 성공한 궤적만 디스크에 저장 → 이것을 "시연"으로 삼아 과제별 generalist 를 Diffusion Policy 로 BC. DAgger 처럼 student 상태에 다시 라벨을 붙이지 않는다 (p.14–15, §6.4).
  • 망: 고유감각 + 물체 위치 → 3 층 MLP (512, 512, 512), ELU, 출력 64. 깊이 → ResNet-18, BatchNorm 을 모두 GroupNorm 으로 교체. 특징을 이어 diffusion 모델 입력으로.
  • diffusion 설정: 제곱 코사인 잡음 일정, 학습 확산 단계 100 (Diffusion Policy 와 같음). AdamW 학습률 1e-4, weight decay 1e-5, 배치 128. 가중치 지수 이동 평균을 평가·배포에 사용.

11. 우리에게 가져올 것

  1. 접촉 표식 보상을 "옆면 조이기" 꼴로: 그림 5 의 "좌·우 옆면 중심" 표식이 우리 파지 그대로다. 손가락 끝 4 점 대신 손마다 손바닥 패드 중심 1 점(손끝 쪽 기준점은 패드 중심보다 7 cm 앞이었다는 내부 실측이 있으니 패드 중심으로)을 쓰고, 표식은 박스 치수·자세에서 좌·우 옆면 위에 격자로 여러 개 생성한다. d = 가장 가까운 표식까지 거리이므로 표식을 옆면 중앙에만 두지 말고 도달 가능한 영역(쪼그림에서 중앙은 20 cm 모자란다는 v2 실측)까지 퍼뜨리면 "닿지 않는 중앙"을 쫓는 문제가 사라진다. 꼴은 1 / (1 + α d) 로 두고 α 는 d = 10 cm 에서 0.5 가 되도록 α = 10 m−1 에서 시작(우리 선택).
  2. 손별 항은 합이 아니라 min(또는 곱)으로: 논문 식은 왼·오른 항의 합이라 한 손만 붙어도 절반을 받는다 — v2 의 한 손 밀기 국소해가 정확히 이 꼴이다. r = min(rL, rR) 로 바꾸고, 물체 목표(들어 올림·자세) 항은 두 손 모두 표식 근처일 때만 켠다.
  3. student 에 박스 위치를 명시 입력으로: 깊이만 0/10 대 깊이 + 위치 10/10(들기). K1 엔 3 인칭 카메라가 없으므로 ① D436 깊이에서 바닥 평면을 빼고 박스 점군 중심을 직접 계산해 넣거나(관측 잡음 0.02 m 수준으로 학습), ② student 에 "박스 위치 예측" 보조 머리를 붙인다. 가까이 가서 시야를 벗어나면 마지막 추정을 유지하는 처리가 함께 필요하다.
  4. teacher actor 는 student 가 추정할 수 있는 것만: 전문가 actor = 물체 위치 + 관절, 나머지(속도, 손끝, 물체 방향·속도, 질량·마찰·모양 배율)는 critic 전용. 우리도 박스 질량·마찰·손–박스 접촉력은 critic 으로 옮기고 actor 엔 박스 위치·yaw·크기(잡음 포함) + 고유감각만 남긴 teacher 를 한 번 학습해 성공률 하락 폭부터 잰다.
  5. 팔 autotune: 같은 관절 목표 시퀀스를 실기 K1 팔(맨손 + 박스 0.5 / 2 kg 들고)과 Isaac(Newton) 모집단 K 개에 재생해 armature·감쇠·마찰·effort 를 추종 MSE 최소로 고른다. 4 분 미만 데이터로 실기 성공이 0/10 → 8/10 갈렸다(표 1). kp 22.3 팔은 조이기 힘이 추종 오차에서 나오므로 이 맞춤의 값어치가 다지 손보다 크다(추론). 실기 추종이 Isaac 보다 5–15 ms 늦다는 내부 실측도 같은 틀에 지연 파라미터로 넣는다.
  6. "놀아 본" 상태로 리셋: 건네기에서 학습 성공 시드 0 → 30 %. 우리는 시뮬 원격조종 대신 v2 teacher 의 성공 에피소드에서 쪼그린 채 두 손이 박스 옆면 가까이 온 상태를 모아 리셋 분포에 섞는다(추론 — 시연 궤적이 아니라 상태만이라는 점이 같다).
  7. DR 값 중 옮길 만한 것: PD P 이득 × U(0.8, 1.1), D 이득 × U(0.7, 1.2); 박스에 무작위 힘(확률 0.2, 0.1 s 마다 0.99 배 감쇠, 크기는 2 kg 박스에 맞춰 다시); 프레임·행동 지연 확률 각 0.1; 깊이 카메라 회전 잡음 5°(우리 실측 편차보다 크니 상한으로만).
  8. 분할 정복이 필요해지면 "다양한 묶음"으로: 실기 최고가 물체 하나씩(40 %)도 전부 하나(23 %)도 아닌 모양 섞은 묶음(90 %)이었다. 단일 teacher 가 바닥 박스에서 막히면, 받침 높이 하나씩 전문가를 나누지 말고 각 전문가가 높이·yaw 를 고르게 섞어 갖게 나눈다(추론).

가져오지 않을 것

  • 물체 질량 0.03–0.1 kg: 우리는 0.5–2 kg. 조이기·미끄럼·팔 처짐이 전혀 다른 영역이다.
  • 성공 궤적 BC(diffusion policy): 오프라인 BC 는 student 상태 분포를 고치지 못한다. 5 Hz 고정 기저 탁상 과제라 통했을 수 있다. 우리는 DAgger(+ student RL) 유지.
  • 절대 관절 목표 출력: v2 의 포화·추종 불가 문제가 절대 출력에서 나왔다. 증분 출력 유지.
  • 관절 관측 잡음 N(0, 0.4): 단위·정규화가 불명이라 값 자체를 옮기면 위험하다.
  • 3 인칭 카메라 + SAM2 파이프라인: 접근·운반으로 갈 우리 과제엔 고정 카메라가 없다.
  • 손가락 끝 기반 표식 거리: 고무 공 손엔 손가락이 없다 — 패드 중심 1 점으로.
