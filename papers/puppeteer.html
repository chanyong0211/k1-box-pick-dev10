1. 문제와 과제

  • 문제: 56 자유도 휴머노이드를 시각으로 전신 제어하면서, 보상 설계·기술 프리미티브 없이 "사람 같은" 동작을 얻기 (p.1–2).
  • 해법: 두 개의 같은 알고리즘(TD-MPC2) 에이전트. 하위는 MoCap 추적을 한 번 학습해 재사용, 상위는 과제 보상으로 하위에 끝점 명령을 낸다 (p.3–4).

2. 시스템 구조

3인칭 RGB 64×64 + 고유감각 212→ 상위 TD-MPC2 (학습, MPPI 계획)→ a ∈ [−1, 1]15 × 0.3→ + 현재 끝점 5점 위치 = 레퍼런스→ 하위 TD-MPC2 추적 (고정, MPPI 계획)→ 56 관절 행동 → MuJoCo (제어 0.03 s)
  • 같은 주기: k = 1 — 상위 한 스텝에 하위 한 스텝 (p.6, 표 5). 상위는 이전 명령 달성 여부와 상관없이 고정 주기로 명령 (p.5).
  • 두 단계 학습: ① 추적 월드모델 10M 스텝(약 12일) ② 과제별 상위 3M 스텝(약 4일), 둘 다 RTX 3090 한 장 (p.6).
  • TD-MPC2 6 요소 (식 1): 인코더 z = h(s), 잠재 동역학 z′ = d(z, a), 보상 R(z, a), 종료 D(z, a)(새로 추가), Q(z, a), 정책 사전 p(z). 관측을 복원하지 않는 디코더 없는 모델.
  • 종료 처리 (식 2): L = LTD-MPC2 + α·CE(δ̂, δ), α = 0.1. TD 목표는 종료에서 자르고, 계획 롤아웃은 예측 종료 확률을 누적(최대 1)해 부드럽게 자름 (p.5, 코드 _estimate_value).

4. 보상 · 종료 · 커리큘럼

  • 하위 보상: CoMic(Hasenclever 2020) 추적 보상으로 모든 전이에 이름표 (p.4, 부록 D). 가중치는 논문에 없음.
  • 하위 데이터: MoCapAct "small" — 836 클립 전문가 정책 × 잡음 롤아웃 20 = 16,720 궤적(차선). 매 배치 오프라인 50 % + 온라인 50 % (p.4, 부록 D). 온라인 에피소드마다 새 클립, 최대 1,000 스텝, 클립 끝까지 가면 성공 (humanoid.py).
  • 상위 보상: 1절 표의 과제 보상만. 자연스러움 항 없음.
  • 커리큘럼: 없음. 대신 "상위 사전학습" 실험: corridor 에서 학습한 상위로 다른 시각 과제를 미세조정 (그림 8 오른쪽).
  • 도메인 무작위화: 논문에 없음 (환경 배치 무작위만).

9. 코드에서 확인한 것

  • 하위 감싸기: transfer.py TransferWrapper — 하위 체크포인트를 읽어 eval(), 행동 공간을 15차원으로 재정의, 매 스텝 아래처럼 하위 관측을 만든다. 
    action = action * self.cfg.action_scale            # 0.3
low_level_obs['walker/reference_appendages_pos'] = \
    low_level_obs['walker/appendages_pos'] + action
action = self.low_level_policy.act(low_level_obs, t0=self._t==0, eval_mode=True)
    즉 상위 명령은 현재 실측 끝점 위치 기준 ±0.3 델타다. 직전 명령을 누적하는 델타가 아니라서, 레퍼런스가 실제 몸에서 0.3 이상 멀어질 수 없다.
  • 제어 주기: control_timestep=0.03, 물리는 dm_control 기본 (make_env). 시간 제한 500 스텝.
  • 하위 학습 env: tracking.py — ref_steps=[1], 행동 잡음 0.01, 최대 1,000 스텝.
  • 계획 반복 휴리스틱: tdmpc2.py iterations += 2*int(action_dim >= 20).
  • 가중치: 저장소에 없음. README 의 Google Drive 링크로 배포. Git LFS 포인터 아님.

10. 한계

  • 저자 언급: 과제가 주로 시각-이동, 두 계층 중 하나만 사전학습 (p.10).
  • 조작·지속 접촉 과제가 없다. 실기 없음. 3인칭 카메라.
  • 모델 기반 + 두 단계 MPPI 라 추론 88.2 ms/스텝, 하위 학습 12일. 우리 PPO·Isaac Lab 스택과 다르다.
  • "자연스러움"은 하위 추적 사전이 주는 효과이고, 과제 보상 자체는 평면 TD-MPC2 와 비슷하다.

11. 우리에게 가져올 것

  1. 실측 기준 델타 명령: 골반 높이·pitch 명령 = dev12 가 실제로 만든 현재 값 + k·a (a ∈ [−1, 1]). 명령이 실제 상태에서 최대 k 만 앞서므로 v2 의 "추종기가 못 따라가는 출력"(허리)을 구조적으로 막는다. k 는 dev12 가 상위 한 스텝 동안 따라잡는 양 정도로(측정 필요). 단, 무거운 박스로 골반이 처지는 정상상태 오차 축에서는 같은 a 를 계속 내야 하므로 직전 명령 누적(VIRAL 식) 델타와 비교 실험할 것.
  2. 하위 고정 + 같은 주기(k = 1)로 시작: 계층 효과가 계획 없이도 나는지 이 논문은 보여 주지 않지만(계획 없음 1.6), 하위 고정·같은 주기 자체는 문제없었다. 명령 묶음(temporal abstraction)은 나중 소거로.
  3. 하위 학습 분포가 상위 성능 상한: 추적 클립 1 % → 21.0, 100 % → 61.7, 오프라인만 성공 6.2 %. dev12 명령 샘플러가 pelvis_pick 이 낼 조합(정지 쪼그림 0.335–0.42 m — 보행 범위 밖 — + pitch + 손 하중)을 덮는지 먼저 확인.
  4. 성공률 말고 자세 지표도 기록: 같은 보상에서 몸통 높이 96.0 vs 85.9 cm, 사람 선호 97.8 %. 우리도 성공률과 함께 골반 높이·pitch 분포, 넘어짐 직전 자세를 평가셋에 남긴다.
  5. 상위 사전학습 → 미세조정: 접근·운반 단계를 붙일 때 박스 집기 상위를 초기값으로 쓰면 초반이 빨라진다는 근거.

가져오지 말 것

  • TD-MPC2·MPPI: 추론 88 ms/스텝, 5M 모델에 512 표본 × 6–8 반복. 우리 PPO 스택과 맞지 않고 K1 온보드 실시간도 어렵다(추정).
  • 3인칭 RGB 직접 학습: 로봇에 없는 시점. 우리는 머리 D436 깊이 + 증류.
  • 끝점(손·발) 명령 인터페이스로 dev12 교체: 하위 재학습이 필요하다. 지금은 골반 명령 + 상체 관절 유지.
