1. 문제와 과제

  • 두 문제 (p.1–2): ① sim2real 깊이 잡음이 cm 단위 정밀 과제(계단)를 망침, ② 지형마다 학습 목표가 충돌해 정책 하나로 다 배우기 어려움 (그래서 지형별 전문가 → 증류를 하던 기존 방식은 학습 비용이 큼).
  • 학습 지형 (p.3, 그림 2): 계단 오르기, 계단 내리기, 물결, 높은 단 오르기, 높은 단 내리기, 틈. 지형마다 난이도 20 단계 커리큘럼.
  • 지형 범주 K = 3 (p.4): ① 계단·단(오르내리기 넷), ② 틈 건너기, ③ 거친 지형.
  • 평가 지형 (p.6): 계단 단 높이 15 cm·폭 30 cm(오르기·내리기), 틈 0.45 m, 단 0.40 m. 설정마다 병렬 env 1,024 개 × 100 에피소드.

2. 시스템 구조

1 단계: 특권 RL (teacher)

높이 스캔 21×33 (1.6 × 1.0 m, 0.05 m 간격) → MLP 인코더 128+ 고유감각 96→ GRU 256 → actor MLP → 관절 목표 29
지형 표지 k(s) ∈ {1, 2, 3}→ critic 머리 k 선택 (계단·틈·일반)+ AMP 판별기 k 선택 → 스타일 보상

2 단계: 시각 인지 행동 증류 (student)

시뮬 좌·우 깊이 렌더→ 8 단계 잡음 생성 (표 II)→ 잡음 깊이 24×32 → CNN 인코더 128+ 고유감각 96→ GRU 256 → actor → 관절 29
고정 teacher (깨끗한 높이 스캔)→ 행동 평균 μpriv = 정답 라벨→ student 가 직접 굴린 상태에서 MSE (DAgger 식)

점선 = 고정. 배포는 student 하나가 로봇 온보드에서 50 Hz (p.8).

  • teacher 와 student 는 외부 지각 인코더만 다르고 GRU·actor 구조는 같음. 증류 뒤 깊이 인코더 출력이 높이 스캔 임베딩 자리를 대신함 (p.6, p.12).
  • 부록 A 는 "student CNN 이 teacher MLP 인코더 출력과 맞도록 배운다"고 쓰지만, 식 12 손실에는 잠재 일치 항이 따로 없다. 행동 손실로 간접적으로 맞춘다는 뜻인지 불명 (p.12).
  • student GRU·actor 를 teacher 가중치로 초기화하는지, 고정하는지는 논문에 없음.

스테레오 융합의 동작 (식 1–2): 시뮬에서 왼·오른 시점 깊이를 둘 다 렌더 → 왼 영상 픽셀 (u, v) 마다 대응 열 ur = u − fxb / (dleft(u, v) + 10−6) → |dleft − dright(ur, v)| 가 τ · dleft 보다 작으면 dleft, 아니면 0. 즉 한쪽 눈에만 보이는 가장자리·가림 경계가 구멍이 된다.

표 II 는 가우시안 계수를 "매 프레임"으로, 본문은 "env 마다 뽑아 장치 간 차이를 흉내"로 적어 서로 다르다 (p.3–4).

6. teacher → student / 증류

L_total = L_behavior + λ_denoise · L_denoise + λ_kl · L_kl,     λ_denoise = λ_kl = 0.1      (식 12)
L_behavior = E_s ‖ μ_deploy(s) − μ_priv(s) ‖²         (student: 잡음 깊이 + 고유감각, teacher: 깨끗한 높이 스캔)
L_denoise  = E ‖ E(d) − E(d̃) ‖²                        (같은 장면의 깨끗한 깊이 d 와 잡음 깊이 d̃ 의 인코더 출력을 같게)
L_kl       = KL( N(μ, diag σ²) ‖ N(0, I) ),  μ·σ² = 배치 안 인코더 출력의 경험 평균·분산   (특징 붕괴 방지)
  • DAgger 식: student 가 환경을 굴리고 teacher 가 그 상태에 라벨을 붙임 (p.5).
  • 하이퍼파라미터 (p.13, 표 XII): env 당 반복 스텝 800, 총 4,000 반복, One Cycle 학습률(초기 1e-3, peak/init 10, final/init 50 — 표기 그대로), 기울기 누적 10, 최대 기울기 노름 1.0, 행동 손실 1.0, λdenoise 0.1, λkl 0.1, EMA 0.997.
  • student 행동 std 는 0.1 고정 (p.12, 표 X).

7. 결과

평가 방법: RDT-Bench (p.6, 부록 C)

  • 실기 깊이 약 2 시간(약 200,000 장, 24×32)과 시뮬 깊이로 CycleGAN 을 학습해, 평가 때만 시뮬 깊이를 실기풍으로 바꿔 넣음. 학습 증강은 방법마다 자기 것.
  • 번역 품질 (p.14, 표 XIII): 번역 없는 FID 67.2 → sim→real 23.4 (real→sim 21.7), KID 8.2 / 7.6 (×10−3), 순환 SSIM 0.89 / 0.91, PSNR 28.3 / 29.1 dB, LPIPS 0.12 / 0.11. FID 는 128×128 로 키워 계산.
  • CycleGAN 설정 (p.14, 표 XIV): 생성기 ResNet 9 블록, 판별기 PatchGAN 70×70, 첫 층 필터 64, instance norm, 배치 64, 200 epoch, Adam 2e-4 (β 0.5, 0.999), 100 epoch 뒤 선형 감소, λcyc 10, λidt 0.5, 학습/검증 90/10 %.
  • 지표: 성공률 SR, 평균 기계 전력 P = (1/T) Σ ‖τ ⊙ q̇‖ (×10 W), 전력 악화율 PDR = (PRDT − Pclean) / Pclean.

  • 실패 분석: 내리기에서만 실패. 내려갈 때는 중력이 작은 오차를 되돌릴 수 없는 앞쏠림으로 키우고, 디딜 자리가 지금 단 모서리에 가려 스테레오 인공물이 가장 심한 곳이기 때문 → 가까운 거리 고해상도 깊이나 예측 발 디딤이 필요하다고 결론 (p.8).
  • 다른 로봇: Unitree G1 + D435i 에서 계단 오르기 15/15, 플랫폼별 적응 없음. 오르기 한 종류만 시험 (p.15, 표 XVI).

10. 한계

  • 평가가 시뮬 안: 표 IV–VII 의 모든 비교는 CycleGAN 실기풍 깊이를 넣은 시뮬 결과다. 실기 비교(기준선 대비)는 없고, 실기는 전체 방법 하나 90 회뿐.
  • 수치가 지나치게 매끈: 5 시드 표준편차가 대부분 ±0.2–2 %p 라 시드 사이 RL 편차로는 드물게 작다. 표 VI 본문·표 수치 불일치, 표 II·본문의 계수 추출 시점 불일치도 있다.
  • 빠진 정보: 시뮬레이터, teacher PPO 설정, env 수, 학습 시간, 공통 보상·가중치, 종료 조건, 고유감각 96 차원 구성, 지연 프레임 주기.
  • 저자 언급: 계단 내리기가 오르기보다 약함 (p.8).
  • 우리와의 거리: 조작·접촉 과제가 아니고 계층 구조도 없다. 가져올 수 있는 것은 깊이 잡음 모형과 증류 손실뿐.

11. 우리에게 가져올 것

  1. 스테레오 융합 구멍 모형 (빼면 98.9 → 90.4 %, 가장 큰 단일 효과). D436 도 스테레오이고 무효 픽셀을 0 으로 내므로 식 1–2 를 그대로 쓸 수 있다: 왼·오른 IR 시점(베이스라인 49.858 mm, 깊이 원점 = 왼쪽 IR — 내부 기록)에서 레이캐스트 깊이를 둘 다 만들고, 일관성 검사 |dL − dR(ur, v)| 가 τ · dL 이상이면 0. τ ∼ U[0.05, 0.20] 로 시작. 박스 옆면 가장자리·손과 박스가 겹치는 경계에 구멍이 생기는데, 바로 손바닥을 대야 하는 자리라 student 가 실기에서 보는 모양과 가까워진다(추론). 26×64 이면 레이가 시점당 1,664 개라 비용은 작다.
  2. student 증류 손실에 두 항 추가: L = 행동 손실 + 0.1 · ‖E(d) − E(d̃)‖² + 0.1 · KL(배치 특징 ‖ N(0, I)). 시뮬에서 깨끗한 깊이 d 를 잡음 깊이 d̃ 와 같이 렌더하면 되므로 데이터 비용이 없다. 근거: Ldenoise 를 빼면 98.9 → 93.4 %, 둘 다 빼면(BC 만) 86.0 %. v2 의 student 격차(teacher 90 % 대 student 69 %)를 좁힐 후보 중 가장 싼 것.
  3. student 학습 세부: 행동 std 0.1 고정, 최대 기울기 노름 1.0, 가중치 EMA 0.997 을 평가·배포에 사용 — 체크포인트마다 성공률이 출렁이던 v2 에 EMA 는 바로 시험할 만하다(추론).
  4. 지연은 "에피소드마다 한 번 뽑아 고정"하는 꼴만 가져오고, 값은 우리 실측(D436 가장 최근 프레임 나이 14–45 ms, 위상 모형 — dev9 depth_obs.py camera_model)으로. NYST 의 "2–4 프레임"은 프레임 주기가 적혀 있지 않아 옮길 수 없다.
  5. 외부 파라미터 DR 은 공칭값을 먼저 고친 뒤: NYST ±5 cm · ±0.1 rad(5.7°) 대신, 우리는 모델 장착값이 8 cm 높다는 실측(dev10 camera_mount.py 가 단일 출처)을 반영하고, 녹화마다 실측 편차(높이 +3.1–4.6 cm, 아래각 −0.1 – −1.3°, dev9)에 맞춰 ±3 cm · ±1.5° 정도로. ±0.1 rad 는 우리가 넣을 ±1.5° 의 약 4 배라 박스 거리 단서를 불필요하게 흐린다(추론).
  6. 평가용 "실기풍 깊이" 묶음: 학습엔 쓰지 않고 체크포인트 선택·회귀 시험용으로. CycleGAN 까지 가지 않더라도, 실기 bag 의 박스 장면 깊이와 시뮬 깊이를 같은 통계(구멍 비율, 이웃 상관, 프레임 간 깜빡임)로 나란히 재는 표를 먼저 만든다.

가져오지 않을 것

  • 잡음 계수 범위 그대로: ci ∼ U(−0.03, 0.03) 은 1.0 m 에서 σ 가 보통 약 2.4 cm, 최대 9 cm(계산). D436 스테레오 이론값 σz = z² · 0.1 px / (f · b) 는 1.0 m 에서 약 5 mm(D436 기준표 §7). Gemini 336L 용 값을 옮기면 우리 박스 거리(약 0.5–1.2 m, 추론)에서 잡음을 한 자릿수 크게 넣는다. 우리 실기 녹화로 다시 잴 것(표현이 바뀌면 다시 잰다는 내부 교훈과 같음).
  • 다중 critic·다중 AMP: 지형마다 보상 집합이 달라서 효과가 난 장치다. 박스 높이 묶음(바닥 대 받침)마다 보상을 달리 쓰게 될 때만 다시 볼 것.
  • 높이 스캔 teacher·지형 보상: 우리 teacher 는 박스 자세·크기를 본다.
  • 깊이 한 장 + GRU 로 바꾸기: 6 장 쌓기 대 GRU 비교 절제가 논문에 없다. 지금 구조를 유지하고, 바꾸려면 따로 A/B.
  • [0.3, 2.0] m 자르기 그대로: 쪼그려 가까이 갔을 때 박스 윗면까지 거리가 0.3 m 가까이 내려갈 수 있다(추론). 우리 자르기 하한은 D436 실측 최소 거리와 쪼그림 기하로 정한다.
